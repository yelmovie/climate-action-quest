# 공통 아이콘 점검과 제작 기준

2026-10-21 · 초기 자료에는 실행 UI 코드가 없었다. 공통 아이콘은 새 `src/icons.js`의 직접 제작 SVG로 통일한다.

| 위치·용도 | 기존 이모지 | 제작 방식 | 규격 |
|---|---|---|---|
| 홈·이전·소리·설정 | 실행 코드 없음 | 동일 stroke·viewBox의 SVG | viewBox 0 0 24 24, 버튼 48px 이상 |
| 체크·잠금·다음·닫기 | 실행 코드 없음 | SVG 상태 표시, 문구 병행 | SVG 24px 기준 |
| 관측·연결·실험·생활·도시 | 실행 코드 없음 | 단순 기능 SVG | SVG 24px 기준 |
| 보상 별·연구 기록·자료 내려받기 | 실행 코드 없음 | SVG 상태·기능 아이콘 | SVG 24px 기준 |

기능 아이콘은 래스터 생성을 하지 않는다. 별·집·화살표·스피커·톱니 등은 코드로 정확한 크기와 대비를 유지한다. 그림 자산인 지도·주인공·NPC는 기능 아이콘과 구분해 이미지 생성 이력에 기록한다. 실제 코드에 추가되는 이모지는 최종 검수에서 다시 확인하며, 이 문서가 검사 완료 증거는 아니다.
