# 기후 미래 작전실 장별 시나리오 논의안

작성일: 2026-10-14. 현재 단계는 시나리오 대화와 참고 자료 정리이며, PRD·TRD 확정이나 MVP 구현 단계가 아니다.

## 확인한 자료와 우선하는 방향

사용자의 최신 요청과 폴더의 기존 설계 문서, 참고 이미지 23장을 기준으로 정리했다. 공유 대화 링크는 본문을 열지 못했으므로 그 대화 전체를 확인한 것으로 간주하지 않는다. 기존 문서의 일부 P 번호가 서로 달라, 아래에서는 상세 화면 목록의 순서대로 활동 01~10을 사용한다.

- 메인 화면 다음에 자연 속 스테이지 선택 맵이 나온다.
- 스테이지 선택 맵에만 위에서 비스듬히 내려다보는 2.5D 픽셀아트 RPG 표현과 캐릭터 이동을 적용한다.
- 장소에 들어가면 기존 샘플에 가까운 2D 활동 화면으로 전환한다. 활동 03의 도시 탐색도 2D 파노라마와 스캐너로 바꾼다.
- 사용자의 후속 선택에 따라 해수면 실험·도시 설계·스트레스 테스트는 2D 화면 안의 중앙 모형만 회전 가능한 3D로 만든다.
- 기존 이미지는 부드러운 일러스트 계열이다. 활동 전체를 픽셀아트로 바꾸지 않는다.
- 기존 설계의 5개 미션과 10개 핵심 활동을 이야기의 뼈대로 유지한다.

## 이야기의 출발점

숲과 강이 있는 자연 연구기지에 기후 미래 작전실이 있다. 도시의 관측 자료와 대응 자료를 연결하던 시스템이 끊어져, 다섯 연구 구역이 서로 정보를 주고받지 못한다. 학생은 연구 대원이 되어 잎새 다람쥐와 물방울 수달의 도움을 받아 관측·관련성·영향·생활 대응·도시 설계 기록을 다시 모은다.

목표는 관측 자료를 근거로 판단하고, 대응안을 시험해 작전실의 연구 시스템을 복구하는 것이다. 코어를 켜면 현실의 기후변화가 즉시 해결되는 이야기로 표현하지 않는다.

맵에서 직접 조작하는 주인공은 별도 학생 연구 대원으로 확정했다. 잎새는 관측과 기록, 물방울은 실험과 재검증을 돕는 안내 NPC를 맡는다. 둘 모두 모든 화면에 등장할 필요는 없다.

## 메인과 자연 속 스테이지 맵

메인은 로고와 연구기지 배경을 사용하는 2D 화면이다. 시작하기·이어하기를 중심으로 구성한다. 연구 의뢰를 받은 뒤 자연 속 맵으로 이동한다.

맵에는 중앙 작전실과 다섯 목적지를 둔다. 장소 이름은 제안이다.

| 장소 | 연결되는 장 | 맵에서 보이는 단서 |
| --- | --- | --- |
| 언덕 관측소 | 1장 이상 신호의 증거 | 작동하지 않는 관측 안테나 |
| 마을 조사소 | 2장 인간 활동의 흔적 | 끊어진 활동 데이터 표시 |
| 물가 실험실 | 3장 미래 영향 실험 | 꺼진 실험 모니터 |
| 생활 연구소 | 4장 나의 생활 대응 | 비어 있는 생활 기록판 |
| 도시 설계소 | 5장 미래도시 대응 설계 | 멈춰 있는 도시 실험판 |

짧은 길을 걷고 입구에 접근하면 장소명과 입장 행동이 나타난다. 반복 이동이 수업 시간을 잡아먹지 않도록 발견한 장소에는 빠른 이동을 제공하는 방향을 제안한다. 각 장을 끝내면 맵으로 돌아와 복구된 시설과 달라진 NPC 반응을 확인한다.

기본 진행은 앞 장의 기록을 다음 장에서 사용하는 순서다. 관리자 전체 해금을 켜면 모든 장소와 활동에 한 번에 접근할 수 있다.

## 장별 시나리오와 학생 행동

### 1장 이상 신호의 증거

잎새의 의뢰: “도시에 이상 신호가 보이는데, 어떤 자료를 봐야 정확히 알 수 있을까?”

- 활동 01 도시 이상 신호 스캔: 2D 도시의 네 관측 지점에서 기온·강수·지표·물 등의 자료를 확인한다. 스캐너와 과거·현재 비교를 통해 지점마다 서로 다른 근거 두 개 이상을 보관한다.
- 활동 02 증거 판독실: 자신이 모은 자료로 현상을 판단하고, 근거를 연결한다. 자료가 부족하면 해당 지점으로 돌아가 보완한다.
- 결과물: 기후 신호 관측 기록. 맵의 관측 안테나와 코어 첫 표시가 켜진다.
- 다음 장의 이유: 현상을 확인했으니, 도시의 어떤 활동과 관련이 있는지 조사한다.

한 번의 폭우나 추위를 그 자체로 기후변화의 증거라고 단정하지 않도록, 여러 해의 비교 자료와 관측의 한계를 반영한다. 실제 자료가 없으면 가상 자료로 표시한다.

### 2장 인간 활동의 흔적

잎새의 의뢰: “겉으로 보이는 모습 말고, 이곳에서 쓰는 에너지와 자원을 찾아보자.”

- 활동 03 도시 활동 스캐너: 학교·집·도로·생산 지역·숲을 2D 장면으로 조사한다. 스캐너가 지나간 곳에 에너지·자원 사용과 숲의 변화가 드러난다.
- 활동 04 관련성 추적망: 수집한 활동을 ‘활동 → 관련 변화 또는 근거 → 기후변화와의 관련성’으로 연결한다. 중간 설명이 비어 있으면 보완한다.
- 결과물: 인간 활동 관련성 지도. 맵의 조사소와 활동 데이터 표시가 복구된다.
- 다음 장의 이유: 관련성을 찾았으니, 변화가 생활과 환경에 어떤 영향을 줄 수 있는지 실험한다.

공장이나 자동차를 무조건 나쁜 대상으로 분류하는 방식은 피한다. 조사한 기록으로 관계를 설명하는 데 초점을 둔다.

### 3장 미래 영향 실험

물방울의 의뢰: “물이 더 높아지면 어느 곳부터 영향을 받을까? 먼저 예상하고 시험해 보자.”

- 활동 05 해수면 미래 실험: 가상 해안도시의 낮은 곳과 높은 곳을 관찰한다. 예상 영향 범위를 표시하고 수위 단계를 바꿔 실행한 뒤 예상과 결과를 겹쳐 본다. 조건을 바꿔 다시 실험한다.
- 활동 06 영향 연쇄 분석: 실험 기록을 이용해 ‘물의 범위 변화 → 길이나 생활공간 변화 → 사람과 생물의 영향’을 연결한다. 생활 영향과 환경 영향을 각각 표현한다.
- 결과물: 미래 영향 예측 보고서. 물가 실험실이 다시 작동한다.
- 다음 장의 이유: 영향을 알게 되었으니, 생활에서 할 수 있는 대응을 비교한다.

2D 활동 화면의 중앙에 회전 가능한 3D 도시 모형을 두고, 시점을 바꾸며 높낮이를 볼 수 있게 한다. 수위 단계는 실제 미터나 특정 연도의 미래 예측값이 아니다.

### 4장 나의 생활 대응

잎새의 의뢰: “무조건 참는 대신, 생활을 지키면서 바꿀 수 있는 선택을 찾아보자.”

- 활동 07 오늘의 기후 선택: 아침·등교·학교·방과후·저녁의 다섯 상황에서 선택한다. 선택에 따라 2D 생활 장면과 기후 부담·생활 만족·사용 자원의 상대 지표가 함께 변한다.
- 활동 08 선택 비교와 실천: 하루의 선택 하나만 바꾸고 나머지 조건을 유지해 결과를 비교한다. 실제 생활에서 실천할 행동 하나를 정한다.
- 결과물: 나의 생활 대응 실천안. 생활 연구소 기록판과 네 번째 코어 표시가 켜진다.
- 다음 장의 이유: 개인의 선택에 더해, 도시가 함께 준비할 대응을 설계한다.

건강과 안전을 포기하는 행동을 보상하지 않는다. 자동차를 한 번 덜 타면 당장 홍수 위험이 줄어드는 식의 직접 연결도 사용하지 않는다.

### 5장 미래도시 대응 설계

물방울의 의뢰: “네가 조사한 도시를 직접 준비시켜 보자. 첫 설계가 충분한지는 시험해야 알 수 있어.”

- 활동 09 미래도시 설계: 3장에서 본 같은 가상 도시의 위험 구역을 살핀다. 제한된 자원으로 도시숲·그늘·쉼터·물 저장·저류 공간 등을 배치하고 이유를 남긴다.
- 활동 10 기후 스트레스 테스트: 많은 비와 폭염 등 정해진 조건으로 시험한다. 취약 구역을 확인하고 배치나 시설을 수정한 뒤 같은 조건에서 다시 시험한다. 수정 전후의 차이를 비교한다.
- 결과물: 검증된 기후 대응 도시 설계도. 다섯 번째 코어 표시가 켜지고 중앙 작전실로 복귀한다.
- 다음 장의 이유: 다섯 연구 결과를 연결해 작전실에 최종 대응안을 적용한다.

배치 도구와 결과 UI는 2D로 구성하고, 중앙에는 활동 05와 같은 3D 도시 모형을 재사용한다. 처음부터 잘 설계한 학생에게 의미 없는 변경을 강요하기보다, 다른 배치와 비교해 최종안을 고르게 하는 개선안도 검토한다.

### 최종 보고와 엔딩

중앙 작전실 안으로 들어가면 다시 2D 화면이다. 학생은 연구 보관함의 다섯 결과를 관측·관련성·영향·생활·도시 슬롯에 연결하고, 최종 설계를 적용한다. 직접 작동 손잡이를 올린 뒤 가장 취약했던 구역의 최종 상태를 확인한다.

엔딩은 학생의 실제 관측·선택·도시 수정 기록을 짧게 보여주고 인증서로 이어진다. MVP에서는 2D 전환과 실제 기록을 사용한 연출이 후보이며, 영상 생성은 이번 요청 범위에 포함하지 않는다.

## 모든 화면에 적용할 공통 UI

| 위치 | 항목 | 동작 원칙 |
| --- | --- | --- |
| 좌측 상단 | 홈 | 진행을 보존하고 메인으로 이동 |
| 좌측 상단 | 이전 페이지 | 현재 흐름의 이전 화면으로 이동. 모달이 열려 있으면 먼저 닫기 |
| 우측 상단 | 소리 | 전체 소리 켜기·끄기, 화면 전환 후에도 유지 |
| 우측 상단 | 톱니바퀴 설정 | 동일한 설정 창 열기 |

메인에서도 아이콘 위치는 유지하고, 이전 화면이 없을 때는 이전 버튼을 비활성으로 표시한다. 터치 대상은 충분히 크게 잡고 아이콘의 의미를 읽을 수 있는 이름을 제공한다.

설정 안의 ‘관리자 전체 해금’은 단일 선택으로 둔다. 장별·섹션별 해금 메뉴를 나누지 않고 다섯 장, 열 활동, 최종 보고와 엔딩을 한 번에 연다. 해금은 접근 제한을 푸는 기능이며 학생의 수행 기록을 완료로 덮어쓰지 않는다. 선행 기록이 필요한 화면을 바로 볼 때는 별도 예시 데이터를 사용하고 예시임을 표시한다. 예시 완료로 학생 인증서가 자동 발급되지 않도록 한다.

## 재미와 몰입을 높일 우선 제안

1. 장을 끝낼 때 같은 맵의 안테나·표지판·연구 장치가 실제로 켜져 진행이 눈에 보이게 한다.
2. 이전에 모은 증거, 실험, 선택, 도시 설계가 다음 활동의 입력이 되게 한다. 활동마다 새 문제로 초기화하지 않는다.
3. 예상이 빗나가면 감점보다 바꾸어 볼 조건을 보여준다. 다시 실험하는 행동 자체가 탐구 경험이 된다.
4. 스캔·와이프 비교·관계 연결·수위 조절·하루 선택·도시 배치처럼 장마다 다른 손 조작을 제공한다.
5. 같은 조건의 전후 비교를 가장 큰 성취감으로 만든다. 의미 없는 재화 수집이나 반복 이동은 추가하지 않는다.
6. NPC는 긴 설명 대신 그 순간의 기록에 반응하는 짧은 대사를 사용한다.

## 대화에서 결정한 뒤 PRD와 TRD로 옮길 항목

- 중앙 실험 모형만 3D로 사용하는 방향은 사용자 선택으로 확정했다.
- 맵의 주인공은 별도 학생 연구 대원으로 확정했다. 잎새와 물방울은 안내 NPC로 유지한다.
- 목표 수업 시간과 기본 활동량. 기존 문서의 상세 성공 조건은 아직 그대로 확정하지 않는다.
- 기존 5개 미션과 위 이야기 연결에 대한 사용자 수정 사항.

PRD에는 확정 시나리오·화면 흐름·성공과 재시도 조건·관리자 전체 해금을 기록한다. TRD에는 맵과 활동 화면의 구현 방식·데이터 연속성·저장·렌더러 경계·대표 기기 성능 기준을 정리한다. 그다음 가장 작은 완주 가능한 MVP를 구현한다.
