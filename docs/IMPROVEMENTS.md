# 기능향상기 · 화면 완성도와 탐구의 연결 강화

2026-10-21 · 비교 기준: 기존 문서·시안 → 실행 가능한 MVP 설계/구현

기존 실행 앱의 버그 수정 기록은 아니다. 이번 작업 시작 시 실행 소스가 없었으므로 이전 이미지를 실제 기능이 있었던 증거로 취급하지 않는다.

| 기존 자료에서 남았던 위험 | 이번 반영 방향 | 확인할 사용자 경험 |
|---|---|---|
| 열 장의 시안이 독립 학습지로 끝날 수 있음 | 수집·실험·선택·배치 기록을 다음 활동에서 재사용 | 내가 모은 자료가 다음 판단의 근거가 됨 |
| 장별 활동이 짧아 탐구가 곧 끝남 | 기획 기준량 36→72 단위, 다른 사례·조건·재시험 | 읽기 분량 대신 직접 해 보는 탐구가 늘어남 |
| 활동마다 카드 선택을 복제할 위험 | 조사·연결·수위·순서·A/B·공간 배치 등 다른 조작 | 시설별로 하는 일이 다르고 학습 목적과 연결됨 |
| 지도 선택이 시설 버튼 목록으로 퇴화할 위험 | 2.5D 픽셀 월드·길 이동·학생·동행 NPC·복구 불빛 | 다음 장소를 찾아가고 완수한 변화가 남음 |
| 3D와 2D 범위가 혼재 | 최신 요청에 따라 시설은 2D로 확정 | 터치 조작과 핵심 탐구에 집중함 |
| 가상 수치가 실제 피해 예측처럼 보일 위험 | 모형·상대 지표 표시, 정확하지 않은 실제 수치 미사용 | 결과를 현실의 확정 예측으로 오해하지 않음 |
| 소리·설정·페이지별 버튼 불일치 | 네 공통 SVG 아이콘, 같은 위치와 설정 순서 | 처음 접한 화면에서도 홈·이전·음소거를 찾음 |
| 드래그가 어려운 학생의 조작 장벽 | 탭→탭 대체, 큰 누를 곳과 문장 안내 | 정교한 마우스 조작 없이 완주 가능 |
| 관리자 기능이 수행 기록을 부풀릴 위험 | 접근 해금과 실제 완료·인증서 조건 분리 | 교사가 원하는 시설을 열어도 학생 기록은 보존 |
| 제공 이미지의 출처·배포 권리를 단정할 위험 | 원본 유지·파생 파일 이력·권리 미확인 표기 | 검수자가 실제로 남은 납품 조건을 식별 |

보상은 단순 재화나 클릭 횟수보다 연구 결과물과 전후 비교로 설계했다. 최종 인증서에는 실제 수행을 사용하며 학습효과나 성취기준 달성의 공식 증명으로 쓰지 않는다. 실제 학생 테스트·실기기·학교망·원본 상업 이용 권리 검토는 별도 확인이 필요하다.
