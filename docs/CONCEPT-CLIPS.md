# 탐구 완료 개념 영상 · 2026-10-28 갱신

다섯 스테이지의 열 활동마다 9초 개념 영상을 연결했다. 실제 활동의 기록을 먼저 저장한 뒤 영상을 연다. 다음 연구는 학생이 버튼을 눌러 진행한다. 영상의 닫기·재생 실패로 기록이나 다음 진행이 사라지지 않는다. 완료한 시설의 개념 영상 버튼과 활동의 캐릭터 힌트에서도 다시 볼 수 있다.

## 컷 설계

각 영상의 자막은 0–3초 관찰, 3–6초 변화, 6–9초 발견으로 구성한다. 장면 전환 또는 그래프·수면·시설의 움직임이 이 흐름을 설명하고, 마지막 0.8초는 결과 구도를 유지한다. 캐릭터를 영상에 새로 그리지 않고 기존 잎새·물방울을 영상 밖의 활동 도움말에 사용한다.

[CAMERA] 고정 카메라, 정면 도식. 차트는 비교 막대가 같은 기준선 안에, 해안은 땅의 높이와 수면이 한 화면 안에, 도시는 여섯 구역이 모두 보이는 구도를 유지한다. 끝에는 비교 결과를 고정한다.

[SCENE] 2026-10-28에 생성한 숲·크림·청록 계열의 장소·시설 일러스트를 SVG 프레임에 넣었다. 그림은 관측소·교실·해안·시설의 실제 형태와 상황을 보여 주고, 비교 막대·수면·진행 표시의 크기와 움직임은 코드로 정한다. 텍스트는 DOM 자막으로 분리해 화면 크기에 따라 확대한다. 효과음은 게임의 소리 설정을 따르고 영상 중 배경음은 멈춘다. 영상 자체는 무음이며 내레이션은 포함하지 않는다.

## 파일과 재현

- `src/concept-data.js`: 제목과 3초 간격 자막. 문구 수정은 재인코딩이 필요 없다.
- `tools/concept-clips/scenes.mjs`: 생성 일러스트와 코드로 계산한 모션을 합성하는 SVG 프레임.
- `tools/concept-clips/render.mjs`: WebP 일러스트를 읽고 sharp로 RGBA 프레임을 만들어 FFmpeg 두 인코더에 직접 전달한다. 대용량 임시 프레임 폴더를 만들지 않는다.
- `assets/concept-art/`: 활동 화면과 영상이 공유하는 생성 일러스트 25장. 투명 배경 대상 그림 11장, 장면 그림 14장으로 총 약 3.47MiB다.
- `references/generated/concept-art/`: 생성 PNG 원본. `scripts/prepare-concept-art.mjs`로 WebP를 만들고 `docs/concept-art-manifest.json`에 크기·용량·원본 해시를 기록한다.
- `assets/concepts/`: 1280×720, 24fps, 9초. 각 클립의 VP9 WebM, H.264 MP4(yuv420p, faststart), 마지막 프레임 WebP. 총 30파일, 약 6.50MiB.
- `src/concept-player.js`: DOM 자막, 일시 정지·이어서 보기, 재생 버튼, 완료 포스터, 닫기 후 디코더 정리.

`npm run concepts:render` 또는 `npm run concepts:render -- water`로 재생성한다. 제작 환경의 기존 sharp·FFmpeg를 사용했다. 다른 환경에서는 sharp를 설치한 패키지의 package.json 절대 경로를 `MEDIA_PACKAGE`, FFmpeg 실행 파일을 `FFMPEG` 환경 변수로 지정한다. 학생용 앱에는 제작 도구나 npm 의존성을 포함하지 않는다.

일러스트는 Codex 내장 `image_gen`으로 생성했다. 프롬프트는 `docs/generated-prompts-core.json`, `docs/generated-prompts-facilities.json`, `docs/generated-prompts-coast.json`, `docs/generated-prompts-scenes-school.json`, `docs/generated-prompts-scenes-home.json`, `docs/generated-prompts-drought.json`에 보존한다. 외부 영상 생성 서비스나 영상 클립은 사용하지 않는다. 2026-10-22의 도형 중심 영상은 이번 일러스트 합성 영상으로 갱신했다.

## 실패·접근성·오프라인

- WebM 실패 시 MP4를 시도한다. 로딩 제한 시간이나 두 형식의 오류에는 마지막 그림과 자막 세 문장으로 대체한다.
- 재생 차단·동작 줄이기 설정에서는 직접 누르는 재생 버튼을 제공한다. 다음 연구 버튼은 계속 사용할 수 있다.
- 숨겨진 탭에서는 영상·소리를 멈춘다. 닫기 시 src를 제거하고 load()로 디코더를 정리한다.
- 배포본은 개념 영상·포스터·효과음도 서비스워커에 저장한다. 캐시가 준비된 브라우저에서 오프라인으로 재생한다. MP4 부분 요청도 온라인 서버와 오프라인 캐시에서 처리한다.
- 실제 iPad·학교 태블릿·전자칠판에서의 최종 터치 감도와 스피커 음량 확인은 별도로 필요하다.
