# 기후 미래 작전실 · PRD

작성: 2026-10-21 · 범위: 완주 가능한 웹 MVP · 기획·제작: 옐샘 & 아이스크림미디어

## 1. 제품의 약속

학생은 연구 대원이 되어 잎새 다람쥐와 물방울 수달을 만나고, 끊어진 다섯 연구 구역을 다시 연결한다. **관측 자료를 모으고, 인간 활동과의 관련성을 설명하고, 영향을 예상·실험한 뒤 생활과 도시의 대응을 시험하는 것**이 게임의 핵심이다. 건물 불빛은 연구 시스템이 복구되었다는 표현이다. 게임을 끝내면 현실의 기후변화가 해결된다고 표현하지 않는다.

배포 대상은 태블릿 가로형 웹 브라우저와 전자칠판이다. 학생 화면에 학년·수업 시간을 고정하지 않는다. 개인정보 입력과 회원 가입은 없다. 기록은 현재 기기의 브라우저에만 남는다.

## 2. 이번 결정과 기준 자료

- 스테이지 선택에만 사선 시점의 **2.5D 픽셀 RPG 지도**를 쓴다. 학생 대원과 따라오는 잎새가 길을 따라 이동한다.
- 시설 내부는 기존 일러스트를 활용하는 **2D 활동**이다. 과거 논의의 회전식 3D 모형은 이번 MVP 범위에서 제외한다.
- 기존 5개 장·10개 핵심 활동의 인과 흐름을 유지한다. 배경을 CSS로 흉내 내는 대신 제공된 일러스트와 새 지도 이미지를 실제로 사용한다.
- 시작 시점 폴더에는 실행 소스가 없었다. 아래의 ‘2배’는 종전 실행 코드 대비 측정값이 아니라 **MVP 기획 기준량 36→72 탐구 단위**를 뜻한다. 각 단위는 서로 다른 자료·상황·조건을 사용한다. 같은 문제의 문구만 바꿔 채우지 않는다.
- 참고: `SCENARIO-DISCUSSION.md`, `references/source-design/climate-future-operations_deep-design_v2.md`, 원본 이미지 23장.

## 4. 학생의 화면 흐름

시작 → 연구 의뢰 이야기 → 걷는 지도 → 시설 의뢰 → 첫 활동 → 두 번째 활동 → 연구 기록 보상 → 복구된 지도 → 다음 시설 → 최종 보고 → 개인 탐구 기록 인증서.

이어하기는 완료한 단계만 기억하는 것이 아니라 진행 중의 선택·실험·배치를 복원한다. 홈으로 돌아가거나 브라우저를 새로고침해도 저장된 탐구 기록을 이어 쓴다. 모든 완료 시설은 다시 방문할 수 있다.

지도에는 중앙 작전실과 다섯 시설이 있다. 다음 시설의 이름표와 입구가 강조된다. 학생은 건물이나 길을 누르거나 방향키·화면 방향판으로 이동한다. 건물 이름표는 키보드로 접근 가능한 실제 버튼이다. 입구에 닿아야 시설로 들어간다. 지도 밖이나 강을 가로질러 순간이동하지 않는다.

## 5. 10개 활동과 2배 분량

| 장·시설 | 활동 | 기획 기준→MVP | 핵심 조작·판단 | 다음 활동에 전달할 것 |
|---|---|---:|---|---|
| 1 언덕 관측소 | 01 도시 이상 신호 스캔 | 4→8 지점 | 관측 위치 선택, 자료 확인, 기록 수집 | 실제로 모은 관측 자료 |
| 1 언덕 관측소 | 02 증거 판독실 | 4→8 사례 | 짧은 현상과 장기 비교를 구별하고 근거 판단 | 기후 신호 관측 기록 |
| 2 마을 조사소 | 03 도시 활동 스캐너 | 5→10 조사 | 학교·집·도로·생산·숲의 활동 조사 | 에너지·자원·숲 변화 기록 |
| 2 마을 조사소 | 04 관련성 추적망 | 4→8 연결 | 활동→중간 변화→관련성을 연결 | 인간 활동 관련성 지도 |
| 3 물가 실험실 | 05 해수면 미래 실험 | 3→6 실험 | 영향 구역 예상→수위 조절→시험→비교 | 예상·조건·실제 영향 기록 |
| 3 물가 실험실 | 06 영향 연쇄 분석 | 4→8 연쇄 | 환경 변화·길과 공간·사람/생물 영향 순서 구성 | 미래 영향 예측 보고서 |
| 4 생활 연구소 | 07 오늘의 기후 선택 | 5→10 상황 | 건강·안전을 지키는 생활 선택과 상대 지표 관찰 | 학생이 선택한 하루 |
| 4 생활 연구소 | 08 선택 비교와 실천 | 2→4 비교 | 한 조건만 바꿔 비교, 실제 할 행동 선택 | 나의 생활 대응 실천안 |
| 5 도시 설계소 | 09 미래도시 설계 | 3→6 구역 | 제한 자원 안에서 시설→구역 탭 배치 | 실제 도시 설계 |
| 5 도시 설계소 | 10 기후 스트레스 테스트 | 2→4 시험 | 폭염·많은 비 시험, 수정, 같은 조건 재시험 | 검증한 기후 대응 도시 설계도 |

합계: 36→72 탐구 단위. 이 수는 객관식 문제 수가 아니다. 위치 조사·예상 실험·비교·배치·재시험을 포함한다. 단계의 길이는 글을 오래 읽게 해서 늘리지 않는다. 빠른 학생도 조건을 바꾸어 확인하고, 아직 어려운 학생은 짧은 피드백으로 다시 시도한다.

### 이해하기 쉬운 활동 설계

- 한 화면의 가장 큰 글자가 지금 할 일을 말한다. ‘판독’ 같은 용어 옆에는 ‘자료를 보고 골라요’처럼 학생 행동을 붙인다.
- 조작은 한 번에 하나씩 드러낸다. ‘예상하기→실험하기→결과 비교’ 순서를 버튼 상태로 알린다.
- 선 연결과 배치는 드래그를 필수로 하지 않는다. **대상 탭→놓을 곳 탭**으로 동일하게 수행한다.
- 오답은 단순한 ‘틀렸어요’ 대신 어떤 자료를 다시 볼지 알려준다. 재시도에 점수·시간 불이익을 주지 않는다.
- 안내 NPC는 누르면 도움을 말한다. 말풍선이 자동으로 활동을 가리지 않는다.
- 가상 자료·수위·상대 지표라는 표시를 해당 실험 안에 둔다. 실제 연도별 예측이나 확정 피해 수치로 오해하지 않게 한다.

## 6. 장별 게임성·보상 매트릭스

| 장 | 긴장·선택 | 손 조작 | 즉시 보상 | 다시 할 학습 이유 |
|---|---|---|---|---|
| 관측 | 한 장면만 보고 단정할지, 비교 자료를 더 볼지 | 위치 조사·관측 기록 | 발견된 자료와 관측소 불빛 | 놓친 근거로 판단을 다시 설명 |
| 관련성 | 겉모습과 실제 에너지·자원 사용 구별 | 장면 조사·관계 연결 | 연결망 완성·조사소 복구 | 다른 활동의 중간 변화를 비교 |
| 영향 | 내 예상과 수위에 따른 결과의 차이 | 구역 예측·슬라이더·연쇄 순서 | 예상/결과 비교·실험실 복구 | 다른 조건에서 영향 범위 재검증 |
| 생활 | 기후 부담과 생활의 필요를 함께 고려 | 상황 선택·A/B 변경 | 지표 변화·실천안·연구소 복구 | 조건 하나를 바꿔 실천 가능한 선택 찾기 |
| 도시 | 한정 자원을 어떤 위험 구역에 쓸지 | 시설 배치·수정·재시험 | 같은 조건의 개선 결과·설계소 복구 | 비와 폭염을 함께 버티는 다른 설계 탐색 |

보상은 단순 클릭 수·정답률·속도로 주지 않는다. 장을 마치면 학생 행동으로 만든 연구 결과물이 남고 지도 시설에 불이 켜진다. 다섯 결과물을 실제로 모으면 최종 보고와 인증서가 열린다. 인증서는 성취기준 완전 달성 판정서가 아니라 **이 게임의 탐구 활동 수행 기록**이다.

## 7. 설정·교사 도구

모든 화면에 홈·이전, 소리·설정 공통 SVG 아이콘을 같은 위치에 배치한다. 지도 진행 숫자·별·가방을 상단 메뉴에 늘리지 않는다.

설정 순서는 배경 음악 → 효과음 → 배경 음악 크기 → 연구 의뢰 다시 보기 → 완료 후 엔딩/인증서 → 앱 정보·배움과 보상 → 학생용 가이드 → 교사용 가이드(성취기준·교사용 도구) → 이미지·소리·저작권(자료 출처) → 기록 초기화·닫기다.

‘관리자 전체 해금’ 버튼 하나로 다섯 장과 열 활동·최종 화면의 접근을 연다. 별도 비밀번호나 단계별 해금은 없다. 이는 보안 기능이 아니다. **접근 해금은 학생 수행 완료와 분리**한다. 예시 데이터로 시설을 살펴봐도 완료 보상과 인증서를 자동 지급하지 않는다. 초기화는 지워질 항목을 구체적으로 안내하고 두 번째 확인에서만 실행하며, 음향 설정은 보존한다.

## 8. 완료 판정·검수 기준

- 기능: 열 활동 전체 완주, 잠금·해금, 중간 저장·복원, 뒤로·홈·재방문, 실제 기록 기반 최종 보고.
- 교육: 관측→근거→관련성→영향→대응이 연결되는지, 날씨/기후 혼동·가상 수치 오해·안전 포기 보상이 없는지 확인.
- UI: 1280×800·1024×768 우선, 906×755·873×580·1920×1080에서 글자·버튼·모달이 잘리지 않는지 실측. 세로는 가로 권장 안내와 사용 가능한 화면 제공.
- 접근성: 48px 이상 터치, 키보드 조작, 포커스 표시, 모달 포커스 복귀, 색 외 정오답 표시, 동작 줄이기.
- 성능: 첫 화면 3초·5MB 이하 목표, 뒤 활동 이미지 지연 로딩. 최초 준비가 끝난 뒤 네트워크 단절에 견디는지 시험.
- 안전: 개인정보·외부 전송·비밀키 없음, 저장 실패 안내, 확인 있는 초기화, 에셋 권리 확인 기록.
- 검수 결과는 별도 `docs/reviews/`에 남긴다. 목표가 10/10이어도 확인하지 않은 항목을 만점으로 쓰지 않는다.

## 9. 납품 전 남는 외부 확인

기존 AI 에셋의 생성 계정·약관·상업 이용 권리는 파일명만으로 증명할 수 없다. 권리자의 자료 확인이 필요하다. 실제 학생의 학습효과, 실제 태블릿·학교망 성능, 배포 주소 동작은 해당 환경에서 최종 확인한다. 로컬 MVP 완성만으로 상업 납품 인증이나 현장 학습효과 입증을 선언하지 않는다.
