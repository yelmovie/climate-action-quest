# 기후 미래 작전실 · 디자인 시스템

작성: 2026-10-21 · 기준: design·iscream-settings 스킬과 제공된 연구기지 일러스트

## 시각 방향

자연 속 작은 연구기지를 탐험하는 교육게임이다. 따뜻한 크림색 조작물, 짙은 청록 글자, 민트·풀색 상태, 호박색 행동 강조를 사용한다. 지도만 픽셀아트이고 시설 내부는 기존의 부드러운 2D 일러스트다. 서로 다른 화면의 그림 스타일을 혼합해 한 장면에 붙이지 않는다.

배경은 실제 이미지로 화면 끝까지 보여준다. 패널은 읽고 조작하는 부분에만 두고, 큰 불투명 컨테이너가 풍경을 전부 가리지 않게 한다. 글자·조작의 가독성이 장식보다 우선이다.

## 토큰과 컴포넌트

색·폰트·여백·모서리·그림자·입력 상태의 단일 구현 기준은 `src/styles.css`의 공통 변수다. 색을 화면별로 흩어 정의하지 않는다. NAVER 공식 NanumSquare Neo Regular 400·Bold 700 WOFF2를 앱 내부에서 제공하고, 기기 기본 한글 글꼴을 대체 글꼴로 둔다. OFL 1.1 원문을 동봉하며 외부 폰트 CDN으로 요청하지 않는다.

| 역할 | 규칙 |

| 제목 | 32~54px 범위의 반응형 크기, 지금 할 일을 가장 크게 |

## 공통 화면 틀

왼쪽 위 홈·이전, 오른쪽 위 소리·설정만 띄운다. 상단 제목 바·하단 진행 바를 만들지 않는다. 지도 별·숫자·가방 메뉴를 추가하지 않는다. 홈 화면에서도 기능의 의미가 분명해야 한다. 활동 제목은 공통 HUD와 겹치지 않는 안전 영역에 둔다.

지도는 화면보다 넓은 하나의 월드다. 학생 대원이 중심 근처에 머물도록 카메라가 움직이고 잎새가 지나온 길을 따라온다. 시설의 잠금·현재 목표·완료는 이름표의 문구와 상태를 함께 바꾼다. 건물 위의 누를 곳은 실제 DOM 버튼이다. 안내 캐릭터 말풍선은 사용자가 눌렀을 때만 열린다.

## 2D 활동

질문·목표 → 큰 조작 영역 → 필요한 자료·피드백 → 다음 행동 하나의 시선 흐름을 만든다. 한 화면에 설명문·카드·상태판을 과도하게 늘리지 않는다. 활동별 기계적 조작은 위치 조사, 자료 판단, 순서 연결, 수위 조절, 선택 비교, 시설 배치로 다르다.

선택 카드는 눌러야 할 대상임을 형태와 안내로 표시한다. 연결·배치에는 탭→탭 대체 조작을 제공한다. 조작 중과 확인 후의 상태를 구별하고, 다음 단계가 열리기 전에는 해당 버튼을 비활성한다.

## 반응형 검수

1280×800·1024×768을 우선한다. 낮은 높이에서는 패널 여백·장식·열 수를 먼저 줄이고 핵심 글자를 마지막에 줄인다. 활동은 실험·자료·선택지·조작 버튼을 스크롤 없이 한 화면에 표시한다. 좁은 세로 화면은 위아래, 가로 화면은 좌우로 배분하며 긴 도움말은 별도 대화상자에 둔다. 390×844·844×390부터 1920×1080까지 전 활동의 초기·결과 상태를 확인한다.

이 문서는 설계 기준이다. 실제 구현의 대비·화면 잘림·포커스 확인 결과는 최종 검수 보고서에 따로 기록한다.

## 2026-11-08 · 스테이지 반응형·자료 시각화

기존 크림·청록 팔레트와 일러스트를 유지한다. 활동 0~3은 같은 눈금의 두 시기 그래프와 수치, 자원 아이콘, 번호가 있는 인과 연결로 자료의 관계를 보여 준다. 슬라이더는 실제 두 기록을 드러내며 중간 측정값을 만들어 표시하지 않는다. 활동 4~7은 지형과 실험 수위를 같은 높이 기준으로 비교하고, 생활 선택의 상대 지표를 3칸 막대와 읽는 방향으로 설명한다. 활동 8~9는 시설 그림·이름·위험 수치를 별도 행에 배치하고 원래→남은 영향, 자원 사용·잔량, 시험 전후 수치를 함께 보여 준다. 수치·판정·저장 규칙은 기존 활동 데이터가 기준이다.

공통 HUD, 학습 영역, 현재 행동·조작 버튼은 서로 공간을 침범하지 않게 배치한다. 조사 지점은 두 열로 배치하되 높이가 낮은 가로 화면에서는 세 열로 바꾼다. 세로 폰에서도 활동 전체가 한 화면에 들어가야 한다. 긴 안내와 교사용 단계 이동은 도움말 대화상자에서 열며 Shift+방향키 이동도 유지한다. 시설 입구는 작은 화면에서 문서 흐름을 유지한다. 버튼 최소 44px, 기본 48px을 지킨다.

`observation-visuals.css`, `impact-visuals.css`, `city-visuals.css`는 자료 표현, `responsive.css`는 공통 공간 배분, 마지막 `activity-screen.css`는 조작 활동의 한 화면 구성을 맡는다. 같은 안내를 제목·자료·힌트에서 반복하지 않는다. 관측 범례와 수치 기준은 한 줄로, 도시 자원 사용·잔량은 한 곳에서 표시한다. 선택 결과 설명은 하단 상태 문장에 한 번만 표시한다.

자동재생은 관측 비교(0), 수위 실험(4), 도시 재난 시험(9)에 제공하고 0.5·1·2배속과 일시정지를 지원한다. 답 고르기·인과 연결·생활 판단·시설 배치를 자동으로 풀지 않는다. 수위 자동재생은 예상을 임의로 선택하지 않고 수위 변화만 관찰하며, 직접 고른 예상은 보존한다. 관측 마무리·실험 마무리·설계 검토·최종 제출은 직접 누른다. 새로고침 뒤에는 재생을 켜지 않고, 페이지 이탈 시 타이머를 해제하며 화면이 숨겨지면 진행을 멈춘다.

## 2026-11-11 납품 점검 반영

도시 운영 미션은 공통 SVG 아이콘과 색상 변수를 사용한다. 제목·닫기·목표·시험 결과·주요 버튼은 고정하고, 짧은 화면에서는 설계 공간만 스크롤한다. 초기화는 확인과 직전 기록 백업을 거친다. 키보드 조작 후 초점과 모달을 닫은 뒤 진입 버튼 초점을 복원한다.

음성 재생 버튼은 최소 48px 높이와 화면별 글자 하한을 적용한다. 활동 하단 도움 버튼도 최소 48px로 맞춘다. 실측 범위와 남은 실기 확인은 `reviews/RELEASE-REVIEW-20261111.md`에 기록한다.
