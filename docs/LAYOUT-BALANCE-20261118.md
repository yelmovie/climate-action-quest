# 놀이 화면 비율·배경 조화 + 중복 조작 버튼 점검 (2026-11-18~19)

기준: `_shared/LAYOUT-BALANCE-DELIVERY-20261118.md`. 측정 스크립트·스크린샷은 `.tmp/layout-balance-20261118/`(Git 미포함)의 `before/`·`after/`.

## 측정 방법

- 뷰포트 1280×800 · 1024×768 · 1920×1080, 화면 18종(홈, 지도, 시설 5, 활동 10, 엔딩). 저장값을 심어 각 화면으로 바로 들어갔다(활동은 빈 기록으로 시작 상태).
- **놀이 영역**: 활동 = `.activity-workspace`, 지도 = `.map-world`, 시설 = 활동 카드 열 `.facility-activities`(학생이 누르는 곳) 그리고 안내 글 `.facility-copy`와 합친 범위.
- **커버율**: 놀이 영역 안 실제 카드·버튼·그림·글이 덮는 화면 비율(8px 격자 표본). 작업 칸은 커도 카드가 작게 떠 있으면 낮게 나온다.

## 중복 조작 버튼 전수 점검

화면마다 보이는 조작 요소(글자·aria-label)를 JS로 뽑아 대조했다(`before/measure.json`, `after/popups.json`). 홈 7, 지도 23, 시설 9, 활동 8~20, 엔딩 7개와 팝업 4종(이야기, 시설 안내, 활동 도움 말풍선, 지도 잎새).

| 후보 | 판단 | 처리 |
|---|---|---|
| 홈 「음성 듣기」+「잎새 인사 듣기」 | 서로 다른 대사(환영 자막 / 캐릭터 말풍선). 11-18 음성 채우기에서 사용자가 청취 확인한 음성이고 `check-voices`·`check-voice-controls`가 둘 다 검사 | 유지 |
| 활동 도움 말풍선의 「음성 듣기」 3개 | 문단마다 다른 대사(개념·안내·힌트). 위와 같은 사용자 확인 음성 | 유지(같은 줄의 작은 칩이라 주 버튼과 무게가 다름) |
| 지도 「손으로 지도 이동」 | 끌기로도 지도가 움직이지만, 켜 두면 탭이 걷기로 바뀌지 않는 별도 모드이고 지도 공격 버튼이 이 버튼 옆에 붙도록 연결됨(`map-attack-control.js`) | 유지 |
| 활동 0·4·9 「자동재생」+「속도」 | 자동재생은 교사 시연용 기능(11-08 결정). 속도는 재생 전에 고르는 흐름이 `check-activity-playback`의 검사 경로 | 유지. 주 버튼은 진한 색 1개, 자동재생은 흰 버튼으로 이미 무게가 다름 |
| 활동 7 비교 카드 + 「A/B 고르기」 버튼 | 11-17 작업에서 이미 카드 자체가 버튼이 되고 별도 버튼은 제거됨 | 이미 정리됨 |
| 시설 「첫/다음 탐구 개념 영상」 | 완료한 활동의 영상만 나오고 활동 카드와 하는 일이 다름 | 유지 |
| 지도 「보고하러 가기」+ 건물 이름표 | 주 버튼 1개 + 직접 조작(건물 누르기). 3초 목표 버튼 | 유지 |

결론: 같은 동작이 두 곳에 있는 버튼, 남은 옛 버튼·개발용 버튼은 찾지 못했다(11-17 3초 규칙 작업에서 정리된 상태). 없앤 버튼 0개. HUD 위치(홈·뒤로 왼쪽 위, 소리·설정 오른쪽 위)와 주 버튼(오른쪽 아래 1개)은 모든 화면에서 같다.
