# 제작기 · 자료를 모아 판단하고 다시 시험하는 기후 탐험

2026-10-21 · 기후 미래 작전실 MVP

출발 자료는 설계 문서와 이미지 23장이었다. 실행 소스는 없었다. 제공된 연구실·도시·생활 장면을 보존하고 실제로 조작할 수 있는 화면을 만드는 것을 MVP의 첫 목표로 삼았다.

이야기는 다섯 연구 구역의 기록이 끊어진 상황에서 시작한다. 학생은 별도의 연구 대원이 되고, 잎새 다람쥐는 관측과 기록을, 물방울 수달은 실험과 재검증을 돕는다. 시스템의 복구를 현실 기후위기의 즉각적 해결로 표현하지 않는다.

선택 지도는 2.5D 픽셀 RPG이고 시설 내부는 2D다. 지도에서 건물 이름만 누르는 메뉴 대신 길을 따라 걷고 다음 연구소를 발견하는 흐름을 설계했다. 실제 학습에서는 배경이 달라도 질문에 답하는 동작만 반복되지 않도록 관측 지점 조사, 자료 판단, 관련성 연결, 수위 실험, 생활 선택 비교, 도시 배치와 스트레스 시험을 나누었다.

분량은 기획 기준 36에서 72 탐구 단위로 확대했다. ‘문제 72개’라는 뜻은 아니다. 위치 조사와 실험의 조건 변경, 예상과 결과 비교, 같은 조건 재시험이 포함된다. 각각의 기록이 다음 활동의 입력이 되도록 해 활동이 따로 놀지 않게 했다.

학생이 어려워할 수 있는 추상적 용어는 행동 문장과 함께 보여주고, 연결과 배치에는 탭→탭 조작을 제공한다. 맞지 않은 예상이나 선택에는 감점보다 다시 확인할 자료를 알려준다. 건강이나 안전을 희생하는 행동을 좋은 기후 선택으로 보상하지 않는다.

그림은 새 지도와 필요한 캐릭터를 제외하면 제공된 것을 재사용한다. 원본을 지우지 않고 최적화 WebP를 별도로 만들었고, 변환 스크립트와 SHA256 이력을 남겼다. 공통 기능 아이콘은 SVG로 직접 제작해 운영체제별로 달라지는 이모지에 의존하지 않는다.

연구 기록·복구된 건물 불빛·최종 수행 인증서를 보상으로 삼는다. 관리자 전체 해금은 화면 접근만 열며 실제로 수행한 기록을 만들어내지 않는다. 교육과정 연계 문구는 공식 교육청 자료로 확인했고, 게임만으로 성취기준 달성을 판정하지 않는다는 안내를 함께 둔다.

구현의 실제 테스트 결과·화면 검수·남은 납품 조건은 `docs/reviews/`의 최종 보고서를 기준으로 한다. 이 제작기는 설계와 제작 의도를 설명하며 실제 학생 대상 효과 검증을 대신하지 않는다.
