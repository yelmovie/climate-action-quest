## 외형과 등장

**하루치 날씨 확성기 / 주황 확성기, 파란 눈송이 카드가 굵은 빨간 장기 추세선을 덮음.** 스테이지 완료 기록 후 지도에 돌아올 때 해당 장소 옆에 등장한다. 기존 주인공·동료·건물의 스타일을 유지하고, 악당과 소품의 접점이 글 없이도 읽히게 그린다. 아래 소품 동작은 지도 위 짧은 장난 컷이다. 활동 화면이나 기존 학습 데이터에는 손대지 않는다.

57px 정적 재시안에서 카드 양옆의 굵은 추세선을 확인했다. 양쪽 자세와 실제 이동 중 검증은 남았다. 카드 좌우로 이어지는 굵은 추세선이 두 방향에서 유지되는지 확인한다.

## 스테이지마다 바뀌는 소품·자세·대사

장소명은 기획상의 연결 기준이다. 활성 버전의 스테이지 ID와 이름을 대조한 뒤 키를 정한다. 선택 구역은 실제 별도 완료 이벤트가 있을 때만 추가한다.

| 장소 | 악당 스프라이트 동작 | 첫 등장 또는 접근 대사 예시 |
|---|---|---|
| 언덕 관측소 | 눈송이 카드로 장기 관측판 덮기 | “오늘 눈 왔으니 이 그림만 보자!” |
| 마을 조사소 | 관련성 지도에 큰 날씨 스티커 붙이기 | “이 스티커면 다 가려지지!” |
| 물가 실험실 | 수위 눈금 앞에 확성기를 대기 | “눈금은 잠깐 안 보이게!” |
| 생활 연구소 | 실천 계획 표지를 툭 뒤집기 | “이 표지는 뒤집어 둘래!” |
| 도시 설계소 | 설계도 위에 날씨 카드 한 장을 올리기 | “도시 지도도 내가 덮었지!” |

상황 대사 예시:

- 접근: “눈송이 카드만 봐 줘!” / “뒤에 있는 기록은 보지 마!”
- 1·2타: “앗, 카드가 들렸어!” / “뒤에 선이 보이잖아!”
- 퇴장: “카드가 접혔네. 간다!” / “그래프는 너희가 봐!”

스테이지 고유 문장을 우선하고, 상황 대사는 연속 반복 없이 고른다. 주인공·보조 캐릭터의 주민 대화와 겹칠 때는 악당 말풍선을 생략한다.

## 세 번의 타격과 접촉 피격

| 사건 | 이 프로젝트의 표현 |
|---|---|
| 1타 · 짧은 명중 | 작은 주황 관측점이 켜짐 |
| 2타 · 더 큰 반동 | 눈송이 카드가 들려 굵은 추세선이 드러남 |
| 3타 · 마무리와 퇴장 | 카드가 ‘팝’ 접히고 확성기가 접혀 빠지며 관측선만 반짝 |
| 주인공 접촉 | 주인공은 모자를 붙잡고 옆으로 한 발 |
| 보조 캐릭터 접촉 | 보조 앵무새는 날개를 벌리고 작은 반동 후 복귀 |
| 악당의 접촉 공격 동작 | 확성기를 한 번 뒤로 당겼다가 앞쪽으로 짧게 내밈. 얇은 관측 신호 고리 한 겹. |
| 타격·퇴장 효과음의 차이 | 팝 → 딱 → 딩 |
| 접촉 효과음 모티프 | ‘팝, 딩’ |

세 타격은 같은 공격 입력이다. 가까이 있는 상태에서 한 입력이 한 타로 계산된다. 접촉 피격은 닿은 쪽만 재생하고 공격 카운트와 학습 진행에는 영향을 주지 않는 것을 권장한다. 소리를 꺼도 표정·자세·게이지로 읽혀야 한다.

## 방향과 시선

[공통 방향 규칙](../../_shared/MAP-VILLAINS-HANDOFF-20261114.md#방향시선공격-자세)을 적용한다. 확성기 얼굴과 팔을 주인공 쪽으로 돌리고, 그래프와 눈송이 카드는 별도 레이어로 둔다. 어느 쪽에서 봐도 빨간 추세선은 왼쪽 아래→오른쪽 위이며, 카드 양쪽의 선과 카드를 쥔 손이 57px에서 보이게 한다.

[57px 실제 지도 수정 전후](../../_scratch/villain-concepts-20261114/readability-09-16/villains-09-16-before-after-57px.png)를 기준으로 양쪽 자세를 확인한다. 현재 시안은 한쪽 자세만 확인했다.

## 제작하고 적용할 순서

1. 기존 진입점 확인: [src/state.js](../src/state.js) · [src/map-repair.js](../src/map-repair.js) · [src/map-sprite.js](../src/map-sprite.js). 활성 지도와 완료 상태, 실제 주인공/보조 지도 원본·이름, 기존 악당/스프라이트·대사·저장부터 확인한다.
2. 기본 악당 한 장, 위 표의 장소별 소품 동작 스트립, 공통 이동/접촉 전조/피격/퇴장 프레임을 제작한다. 주인공·보조 피격은 각각 4~6프레임. 소품이나 배경을 몸통 시트에 같이 구워 넣기 전에 지도 크기에서 알아볼 수 있는지 확인한다.
3. 별도 승인된 구현 단계에서 완료된 장소 좌표에 악당을 붙이고, 기존 HUD 근처에서 공격·타격·피격·퇴장만 연결한다. 기존 이동/화면 전환/복구 상태와 학습 완료/다음 장소 해금은 보존한다.
4. 완료 전/후, 정확한 3타, 두 아군의 개별 접촉, 퇴장 및 재진입, 빠른 연타, 무음·모션 감소·태블릿을 확인한다. 1:1에서 눈송이 카드 뒤 추세선과 가리는 관계가 보여야 다음 단계로 간다.

완료된 것: 정적 이미지 합성과 계획. 남은 것: 기존 시트/캐릭터 일치 확인, 프레임 제작, 대사 최종화, 구현 및 테스트. 06 물의 상태 변화는 참고 전용.
