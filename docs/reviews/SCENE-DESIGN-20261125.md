# 배경과 조작 중심의 전체 화면 고도화

2026-11-25 · 기준 소스 main 5d0c704

## 적용 기준과 근거

사용자 요청대로 기존 장면 그림을 살리고 큰 패널과 반복 설명을 줄였다. 학생이 조작할 위치를 찾도록 안내하며 판단의 정답은 미리 강조하지 않는다. 본문은 20px 이상, 보조 글은 18px 이상, 터치 대상은 44px 이상을 기준으로 했다.

옵시디언의 「기후 미래 작전실」과 「과학34 공통 — 디자인 기준작 비교 2026-11-17」을 읽고 다음 실제 구현을 참고했다.

- 4번 생명 시계 연구실: src/game.css의 글자 역할별 토큰과 src/field-scenes.js의 조작 대상 전체 표시.
- 8번 생명 코드 연구소: src/layout-balance-1118.css의 장면 확대와 내용 높이만큼 사용하는 도구면.
- 12번 보이지 않는 흔적: invisible-traces/src/ui/scenery-surfaces.css의 글자와 면 투명도를 분리한 처리.

## 최종 구성

| 화면 | 적용한 내용 |
|---|---|
| 홈 | 저장한 탐구가 있으면 이어하기를 주 행동으로 표시. 첫 방문은 시작하기 하나 |
| 시설 5곳 | 화면 전체의 밝은 덮개와 큰 이중 카드를 줄이고, 제목·목표 한 줄과 하단의 작은 탐구 입구로 구성 |
| 관측·조사 | 그림을 덮던 버튼 목록을 번호 핀으로 전환. 선택 번호와 자료 제목을 연결하고 시간 손잡이를 명확히 표시 |
| 연결·영향·생활 비교 | 내용 높이만큼의 연결 칸과 선택지. 중복 지시는 한 곳으로 정리하고 모든 판단 선택지를 같은 방식으로 표시 |
| 도시 설계·시험 | 구역과 시설 그림을 중심으로 구성. 폰과 낮은 가로 화면은 시설 선택 드롭다운을 사용하며 정답 시설을 기본 선택하지 않음 |
| 도시 운영 미션 | 시설 선택 → 부지 배치 → 시험 순서에 맞춰 안내 위치가 바뀜. 비용·조건은 필요한 곳에만 표시 |
| 도움·마무리 | 장면 위의 작은 읽기면과 그림 기록 모음으로 정리. 화면 전환 후 남던 이전 이동 안내도 정리 |

공통 읽기 크기와 면 색은 src/styles.css 토큰으로 묶었다. 학습 판정·모델·저장 형식과 인증서 인쇄·봉인 로직은 유지했다.
