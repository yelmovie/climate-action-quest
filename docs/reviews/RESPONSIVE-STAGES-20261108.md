# 스테이지 반응형·학습 시각화 개선

검증일: 2026-11-08

5개 시설 입구와 10개 활동에 적용했다. 스테이지 시각화를 세 묶음으로 병렬 제작하고 공통 레이아웃과 실제 브라우저 검증을 통합했다.

## 개선 내용

| 활동 | 반영한 내용 |
|---|---|
| 0 도시 이상 신호 스캔 | 이전·나중 기록의 고정 수치, 같은 0~8 눈금, 비교 슬라이더. 중간 측정값을 만들어 표시하던 보간을 제거했다. |
| 1 증거 판독실 | 관측과 같은 척도의 수치 그래프, 판단 근거 구분. |
| 2 도시 활동 스캐너 | 에너지·자원 SVG 아이콘, 확인한 활동과 자원 사이 연결 표시. |
| 3 관련성 추적망 | 관찰→이유→관련성의 번호, 선명한 SVG 연결 화살표. |
| 4 해수면 미래 실험 | 땅 높이 1~5와 실험 수위의 같은 척도 단면도, 예상 점선과 실험한 수면. |
| 5 영향 연쇄 분석 | 환경→공간·조건→사람·생물 영향의 단계와 아이콘. |
| 6 오늘의 기후 선택 | 장면·선택 미리보기의 겹침 해소, 상대 지표 3칸 막대와 읽는 방향. |
| 7 선택 비교와 실천 | A/B 상태, 같은 지표를 나란히 비교하는 상대 막대. |
| 8 미래도시 설계 | 그림·시설명·위험 정보의 행 분리, 원래→남은 영향, 자원 사용·잔량. |
| 9 기후 스트레스 테스트 | 시설명 겹침 해소, 남은 영향 수치, 더위·빗물 시험 전후 비교. |

공통 HUD, 힌트·다음 버튼, 자료 안내, 교사 미리보기는 서로 다른 공간을 사용한다. 조사 지점은 좁은 화면에서 격자로 바뀐다. 폰 세로에서는 학습 영역을, 높이 500px 이하 가로 화면에서는 활동 전체를 스크롤한다. 글자·아이콘을 강제로 축소해서 맞추는 방식을 피했다.

## 검증 결과

| 검증 | 결과 |
|---|---|
| 1920×1080, 1366×768, 1280×800, 1024×768, 873×580, 844×390, 390×844, 768×1024 | 248개 화면 상태, 검출 오류 0건 |
| 교사 미리보기: 1280×800, 390×844, 844×390 | 45개 화면, 검출 오류 0건 |
| 힌트·자료 안내 펼침: 같은 3종 크기 | 90회 검사, 검출 오류 0건 |
| 연결 화살표 마감 후 활동 3·5 재검사 | 32개 화면 상태, 검출 오류 0건 |
| 기존 자동 테스트 | 19개 통과 |
| 실제 학습 여정 | 72단위 수행, 10개 활동 누적 완료, 인증서 다운로드·새로고침 복원 통과 |
| 최종 빌드 | 통과, dist 111개 파일 |

검출 항목은 버튼 간 겹침, 그림·시설명 겹침, 헤더·HUD 충돌, 가로 넘침, 버튼 글자 넘침, 가려진 버튼, 닿을 수 없는 조작, 44px 미만 터치 영역이다. 스크롤해서 닿을 수 있는 콘텐츠는 잘림으로 세지 않는다. 실제 스크린샷을 열어 문구·배치·읽기 흐름도 확인했다. 기준 검사에서는 45개 화면 중 5개 화면에서 20건이 검출됐다.

검증 도구: `scripts/check-responsive.mjs`, `npm test`, `scripts/check-full-journey.mjs`, `npm run build`. 브라우저는 macOS Chrome 헤드리스이며 실제 학교 태블릿과 iOS Safari는 미실측이다. 기존 저장·정답 판정·해금 규칙은 변경하지 않았다.

## 변경 파일과 증거

- 공통 배치: `src/responsive.css`, `index.html`
- 활동 자료 표현: `src/observation-visuals.js/.css`, `src/impact-visuals.js/.css`, `src/city-visuals.js/.css`
- 보강 연결: `src/activities.js`
- 기준: `docs/DESIGN-SYSTEM.md`
- 재현 도구: `scripts/check-responsive.mjs` (`--quick`, `--teacher`, `--expanded`, `--activities=3,5`)
- 상세 결과·스크린샷: `.tmp/responsive-check/`
- 학습 여정: `.tmp/full-journey/result.json`
- 코드 관계도: `graphify-out/` 갱신

소스, 빌드, 검증 이미지·로그, 브라우저 임시 프로필과 도구 캐시는 외장 T7 SSD의 프로젝트 경로에서 관리했다. 작업 전에 USB 외장 볼륨, 쓰기 가능 상태와 여유 공간을 확인했다.
