# 조작 활동 한 화면 구성·자동재생

검증일: 2026-11-08

10개 활동의 실험·자료·선택지·조작 버튼을 스크롤 없이 같은 화면에 배치했다. 이전의 작은 화면 스크롤 대응을 대체하며, 이번 기준은 `docs/DESIGN-SYSTEM.md`와 마지막에 로드하는 `src/activity-screen.css`에 반영했다.

## 화면과 안내

- 큰 화면은 실험과 자료를 좌우로, 좁은 세로 화면은 위아래로 배치한다. 실험·조작 공간이 남은 화면을 채운다.
- 현재 할 일은 하단에 한 번만 표시한다. 진행 가능한 다음 버튼은 테두리로 강조한다.
- 활동명·시점·수위·자원·정답 피드백의 중복 설명을 정리했다. 빈 순서 칸의 반복 문장은 넣기 표시로 바꿨다.
- 선택의 이유는 하단 상태 문장에 한 번만 표시한다. 긴 해설과 자료 주의사항은 도움말로 옮겼다.
- 교사용 단계 이동도 도움말에서 열며 Shift+방향키를 유지한다. 활동 조작 공간을 차지하지 않는다.
- 도움말은 별도 대화상자이며 내용이 길면 대화상자만 스크롤한다. 실험 본화면에는 스크롤이 없다.

## 자동재생

| 활동 | 재생 과정 | 직접 하는 부분 |
|---|---|---|
| 0 관측 비교 | 시간 손잡이 이동 → 기록 읽기 → 다음 관측 지점 | 마지막 관측 마무리 |
| 4 수위 실험 | 여섯 수위 조건 연속 관찰 → 결과 확인 | 예상은 직접 선택 가능, 마지막 실험 마무리 |
| 9 도시 시험 | 더위·빗물 시험과 결과 읽기 | 설계 검토·배치, 재시험 시작, 최종 제출 |
| 판단·자원·연결·생활 선택·도시 배치 | 자동으로 풀지 않음 | 학습자가 선택·설계 |

재생·일시정지와 0.5·1·2배속을 지원한다. 수위 자동재생은 예상 답안을 임의로 만들지 않으며 직접 고른 예상은 그대로 보존한다. 재생 속도는 같은 활동의 화면 갱신 동안 유지하고 새로고침 뒤에는 재생을 켜지 않는다. 화면이 숨겨지면 시간을 멈추고 활동을 떠나면 타이머와 이벤트를 해제한다. 자동재생 조작의 키보드 초점도 화면 갱신 뒤 유지한다.

| 수동 학습 여정 | 72단위 수행·10개 활동 누적 완료·인증서 다운로드·새로고침 통과 |
| 최종 빌드 | 통과, dist 113개 파일 |

화면 크기: 1920×1080, 1366×768, 1280×800, 1024×768, 873×580, 844×390, 390×844, 768×1024. macOS Chrome의 실제 DOM 경계·터치 크기·가림·스크롤 높이와 스크린샷으로 확인했다. 실제 학교 태블릿과 iOS Safari는 미실측이다.

기록·정답·해금과 도시 평가의 기존 규칙은 유지했다. 자동 관찰은 학생의 예상이나 정답을 임의로 선택하지 않는다.
