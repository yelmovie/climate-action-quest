# 첫 화면·지도·교사 미리보기 개선 · 2026-10-30

참고: 같은 시리즈 1~4번(우당탕 힘 실험실, 동물기록 복구작전, 초록정원 연구기지, 생명시계 연구실)의 배포 화면.

## 바꾼 것

### 첫 화면
- 1~4번처럼 전면 일러스트 위에 왼쪽 짙은 숲색 그라데이션, 큰 입체 로고, 금색 시작 버튼, 오른쪽 캐릭터 구성으로 바꿨다.
- 로고는 기존 브랜딩 원본(`references/branding/chatgpt_generated_23.png`)을 글자 영역만 잘라 `assets/logo-title.webp`로 만들었다.
- 잎새(돋보기)·물방울(플라스크)은 캐릭터 시트(`references/characters/chatgpt_generated_22.png`)에서 배경만 지워 `assets/home-squirrel.webp`, `assets/home-otter.webp`로 만들었다. 다시 만들 때는 `node scripts/prepare-home-assets.mjs`를 실행한다(sharp 사용, 제작 전용).
- 진행 기록이 있으면 연구 n/10·시설 복구 n/5 진행 막대를 보여 준다.
- 새 이미지 생성 서비스는 쓰지 않았다. 기존 원본 그림만 다시 가공했다.

### 지도
- 3번 초록정원 연구기지의 이동 방식을 따랐다. 지도가 항상 화면을 꽉 채워 위아래 띠가 생기지 않는다.
- 화면을 채우는 배율(cover)의 1.4배로 확대하고, 카메라가 대원을 부드럽게 따라간다. 지도 끝에서는 빈 공간이 보이지 않도록 멈춘다.
- 지도를 8px 이상 끌면 둘러보기, 짧게 누르면 그 길로 걸어가기. **손으로 밀기**를 켜면 누르기로 걷지 않고 끌기만 한다(손 모양 커서). 대원이 다시 움직이면 카메라가 따라가기로 돌아온다.
- **지도 한눈에 보기 / 대원 따라 보기** 전환. 한눈에 보기도 화면을 꽉 채우는 배율이라 띠가 없다. 4:3에 가까운 화면에서는 좌우가 조금 잘리며 끌어서 볼 수 있다.
- 시설 이름표를 번호(1~5)·상태 아이콘이 붙은 알약 모양으로 바꾸고, 다음 목적지에는 "다음 목적지" 표시가 떠 있다.
- 왼쪽 아래: 방향판 + 안내 + 도구 버튼. 오른쪽 아래: 다음 목적지 카드와 금색 이동 버튼.

### 교사용 전체 해금
- 설정 → 교사용 가이드 → 교사용 도구 → 모든 단계 한 번에 열기로 켠다.
- 확인: 시설 5곳·활동 10개가 모두 열리고, 오류 없이 화면이 뜬다. 두 번째 활동들은 "교사용 예시"로 표시되며 완료·인증서에 반영되지 않는다(기존 규칙 유지).
- 켜 있는 동안 지도·시설·활동 화면에 교사 미리보기 도구가 나온다.
  - 오른쪽 아래 금색 **다음 단계 바로 가기**: 문제를 풀지 않고 다음 활동으로 간다(활동 10 다음은 지도).
  - 왼쪽 아래 **이전/다음 화살표**와 현재 위치(n/10 · 활동 이름). 키보드 `Shift + ←/→` 또는 `PageUp/PageDown`.
  - 지도에서는 대원 이동용 방향키와 겹치지 않도록 Shift 조합만 교사 이동에 쓴다.
- 활동 화면에서는 맨 아래 "자료 안내" 줄의 빈 왼쪽과 오른쪽을 함께 써서 활동 영역을 거의 줄이지 않는다.

### 배포
- exFAT 외장 SSD에서 빌드하면 복사 중 macOS `._*` 파일이 생겨 서비스워커 캐시 목록에 들어가고, 이후 삭제되면 설치가 실패했다. 빌드 목록에서 `._*`를 제외했다.
