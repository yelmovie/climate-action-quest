# 16 기후 미래 작전실: 고도화 및 검증

## 결과
학생 탐구 기록과 교사 시연을 분리하고 저장 유실 위험을 줄였다. 기존 5개 장·10개 활동·72개 탐구 단위와 이미지, 개념 영상, 효과음을 보존했다. 원격 배포·커밋·다른 프로젝트 변경은 하지 않았다.

## 실제 개선
- 교사 전체 해금은 학생 상태의 임시 사본에서 실행한다. 시연 중 탐구·완료는 영구 저장되지 않으며, 종료 또는 새로고침하면 학생 기록으로 돌아온다. 시연에서 인증서 발급을 차단했다.
- 손상 JSON·지원하지 않는 저장 버전은 최초 자동 저장으로 덮어쓰지 않는다. 경고와 현재 기록 내려받기를 화면에 계속 제공한다.
- 다른 탭에서 변경한 저장값을 감지하면 덮어쓰지 않고 사용자에게 알린다. localStorage의 원자적 다중 탭 트랜잭션까지 보장하는 것은 아니다.
- 초기화 직전 저장본 한 개를 보관하고, 보관 실패 시 초기화를 취소한다. 설정의 ‘초기화 직전 기록 내려받기’로 내보낼 수 있다. 자동 가져오기 UI는 이번 범위에 없다.
- macOS 외장디스크의 ._* 메타데이터를 JS로 검사하던 빌드 오류를 수정했다. 복사와 Git 표시에서도 제외한다. 메타데이터 파일을 삭제하지 않았다.

## 학습·흥미·과학 검토
관측/판단 → 인간 활동/인과 연결 → 예측 실험/연쇄 영향 → 생활 선택/실천 → 도시 설계/같은 조건 재검증으로 역할이 다르다. 짝수 활동의 실제 결과를 다음 활동이 사용하는 구조이며, 같은 문제를 이름만 바꿔 반복하는 구성은 아니다. 8~10회의 선택 과제는 학급 집중시간에 따라 나누어 운영할 필요가 있다.

하루의 눈·한 주의 추위·한 번의 소나기로 장기 기후를 단정하지 않는 설명, 가상자료 표시, 건강을 희생하는 생활 선택 배제, 도시 재검증의 동일 조건 비교를 유지했다. 성취기준 [4과16-01~03] 연계 표시는 앱 자체 자료에 기반하며 공식 교육과정 대조를 새로 완료했다는 뜻은 아니다. 실생활 실천과 토론은 교실 후속 활동이 필요하며 인증서가 성취기준 전체 달성을 증명하지 않는다는 고지를 유지한다.

기존 21MB 에셋의 일러스트·개념영상·CC0 효과음이 기능에 충분해 추가 생성은 하지 않았다. 새 Momo 음성이나 이미지 생성 모델을 실행하지 않아 기존 사용자 작업과 자원 경쟁을 만들지 않았다.

## 적용한 개선 프롬프트
“16 weatherchange의 원래 단계 구성·과학 설명·에셋을 보존하라. 교사 전체해금을 학생 상태의 임시 사본으로 분리하고 시연 종료/새로고침에서 학생 기록을 복원하라. 손상·미지원 저장과 다른 탭의 새 기록을 덮어쓰지 말고 지속 경고 및 JSON 내보내기를 제공하라. 초기화는 직전 원본의 보관이 성공한 경우에만 수행하고 내려받기 경로를 제공하라. 외장디스크 메타데이터를 빌드에서 제외하라. 회귀 테스트를 먼저 실패시킨 뒤 구현하고, 기존 활동 흐름·오프라인 영상/효과음·네 가지 화면을 검증하라. 커밋/배포/영구삭제는 하지 마라.”

## 범위와 한계
공식 운영시트·1~5 비교는 전체 시리즈의 부모 검토에 합친다. 이 담당 작업에서 해당 시트 최신 원문을 별도로 검증하지 않았다. iPad/Safari/Android 실기기, 터치 전체 경로, 화면낭독기, 학생 대상 재미/학습효과, 실제 저사양 성능·초기 네트워크 로딩은 미검증이다. 기존 전체 layout 스크립트는 localStorage의 adminUnlocked 해금에 의존하여 새 안전 정책과 맞지 않는다. 이번에 새 브라우저 검사로 대체했으며 그 기존 스크립트 전체를 통과했다고 보고하지 않는다. dist는 기존 결과 위에 빌드했으므로 배포 전 별도 깨끗한 출력에서 패키지 확인이 필요하다.
