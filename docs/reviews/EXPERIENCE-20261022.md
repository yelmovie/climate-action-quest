# 기후 미래 작전실 · 개념 영상과 학습 조작 개선 검수

검수일: 2026-10-22. 로컬 Chrome의 독립된 테스트 프로필을 사용했다. 사용자의 실제 브라우저 저장 기록에는 접근하지 않았다.

## 적용 내용

| 범위 | 변경 |
|---|---|
| 완료 개념 영상 | 다섯 스테이지·열 활동에 각각 9초 클립. 기록 저장 후 열고, 자막·일시 정지·다시 보기·명시적인 다음 연구 버튼 제공 |
| 다시 보기 | 완료한 시설의 개념 영상 버튼, 완료 활동의 캐릭터 힌트에서 다시 재생 |
| 화면 균형 | 팝업의 양 축 중앙 정렬. 제목·본문·버튼 크기를 공통화하고 짧은 콘텐츠는 중앙에 배치. 실험·도시의 결과를 나란히 표시 |
| 설명 정리 | 반복된 제목·자료 주의문·선택 버튼을 축약. 과학 모형의 안내는 펼칠 수 있는 자료 안내로 이동 |
| 다음 행동 | 진행을 제목 옆에, 캐릭터의 현재 조작 안내와 다음 행동을 하단에 배치. 영상 닫기 뒤에도 다음 연구 버튼 유지 |
| 보조 캐릭터 | 잎새·물방울의 상황별 한 줄 도움과 추가 힌트. 답 자체보다 조작과 근거 찾기를 안내 |
| 효과음 | 선택·수집·연결·배치·실험·힌트·완료·다시 생각하기를 구분하는 Kenney CC0 효과음 8개 |

## 태블릿에서 가능한 탐구

- 관측: 시간 손잡이로 그래프를 연속 비교하고, 같은 기준선의 이전·나중 기록을 확인한다.
- 판독·조사·관련성: 자료를 판단이나 자원으로 끌어 분류하고, 이유 카드를 빈칸에 연결한다.
- 해안 실험: 예상한 곳을 표시하고 수위를 바꾸어 물결·영향 구역을 비교한다.
- 영향 연결: 카드를 순서 칸에 놓고 이미 놓인 카드의 순서도 바꾼다.
- 생활 선택: 선택에 반응하는 세 지표를 보고, 한 가지 조건만 바꾸는 비교 손잡이로 결과를 살펴본다.
- 도시 설계: 시설을 놓을 때 자원과 구역별 남은 위험이 즉시 바뀐다. 두 날씨 시험 뒤 설계를 검토하고 같은 조건으로 재시험한다.

끌기에는 누르기·키보드로 진행하는 대안을 유지했다. 드래그 취소는 기록을 바꾸지 않으며, 놓은 직후의 실제 다음 입력과 키보드 입력도 받는다.

## 검증 결과

| 검사 | 결과 |
|---|---|
| 기존 학습 모형·진행·저장·경로 테스트 | 15개 통과 |
| 전체 화면·모달·활동 상태 검사 | **300개 조합 통과**, 실행 오류·화면 밖 버튼·조사 지점 겹침·작은 버튼·가로 넘침 없음 |
| 활동 작업 공간 스크롤 | 모든 검사 조합에서 20px 초과 스크롤 없음. 설정·자료의 의도적인 펼침 영역은 내부 스크롤 허용 |
| 실제 브라우저 조작 시나리오 | **19개 통과**. 열 활동 완료, 개념 영상 메타데이터·자막·닫기·계속 진행, 터치 분류·순서 교체·취소, 누르기 대안, 저장, 안전하지 않은 선택 차단, 재설계·재시험, 최종 보고·인증서 |
| 배포·오프라인 검사 | **6개 통과**. MP4 MIME·부분 요청, 오프라인 새로고침·WebM, 캐시 MP4 부분 요청, H.264 대체·탐색, CC0 소리·효과음 끄기, 배경음과 효과음 음량 분리 |
| 빌드 | `npm run build` 통과, 배포 파일 72개. 생성 서비스워커 구문 검사 통과 |

화면 프로필: 906×755, 1024×768, 1280×800, 1440×900, 1920×1080, 873×580. 각 프로필에서 홈·지도·다섯 시설·열 활동, 펼친 설정 네 영역, 이야기 세 장면, 답/실험/설계/재시험 결과, 열 개념 영상, 최종 보고·인증서·초기화 확인을 검사했다. 핵심 화면과 발견된 문제의 캡처를 육안으로 확인했다.

조작 검사는 선행 완료 상태와 일부 반복 라운드를 저장 fixture로 준비했다. 모든 탐구 단위를 한 학생처럼 처음부터 끝까지 수행했다는 뜻은 아니다. Chrome의 터치 이벤트를 사용했으며 실제 기기의 손가락 감도·스피커 음량과 학교망 동시 접속은 별도 확인이 필요하다.

자동 결과: `.tmp/experience-check/layout.json`, `interactions.json`, `delivery.json`. 검사를 다시 실행하면 갱신된다.

## 미디어 출처와 재생 범위

[Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds)의 CC0 배포본을 내려받아 변환했다. 원본 이름·ZIP SHA256·변환 방식·라이선스 원문 위치는 `assets/CREDITS.md`에 기록했다.

개념 영상은 직접 작성한 벡터 도식과 DOM 자막으로 구성하며 내레이션은 없다. WebM·MP4·마지막 프레임 포스터를 함께 제공한다. 캐시 준비 전 처음부터 인터넷 없이 시작하는 것은 지원하지 않는다. 실제 iPad Safari에서의 재생은 별도로 확인해야 한다.
