## 생성 출처·남은 한계
실제 도구는 **built-in image_gen**, 모델명 미공개. Imagen 사용으로 표기하지 않는다. 정확한 프롬프트는 `output/overnight-20261108/generation-prompts.json`에 있다. 생성 성공·파일 저장·실제 참조·브라우저 표시를 각각 확인했다. 그림은 장소 맥락이며 측정값/기후 증거 또는 미래 예측 자료가 아니다. 자료의 가상 상대단계 안내를 유지한다.
학교 태블릿 실기·전자칠판 하드웨어·Safari/인앱 브라우저는 미실측. 기존 모든 실사풍 에셋을 전면 교체한 것은 아니며, 추가 3D·음원·동영상은 제작하지 않았다. 학습효과 인증이나 납품 완전무결 판정은 하지 않는다.
