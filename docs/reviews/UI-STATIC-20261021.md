### 조치 확인 — 저사양 태블릿 모달 blur

- 상태: **STATIC CORRECTED**, 실제 재현 여부 **NOT TESTED**.
- 최초 정적 확인에서 `src/styles.css:303`의 backdrop blur를 발견했다. dokdo-design은 저사양 Chromium의 글자 중복 렌더 위험 때문에 blur 사용을 피하도록 한다.

### P2 — 동작 줄이기에서 지도 카메라 이동 유지

- 상태: **WARNING**, 실제 동작·사용자 영향 **NOT TESTED**.
- 근거: `src/map.js:20`는 보행 프레임만 줄인다. `:34`~`38`에서는 reduced 여부와 무관하게 경로를 따라 이동하고 카메라가 추적한다. dokdo-design의 지도 대체 동작은 순간 이동 또는 이동 정보가 남는 정적 대체를 권장한다.
- 권장: reduced-motion 환경에서 목적지 이동의 최종 콜백·진입 조건은 유지하면서 카메라 이동 대체를 검토한다. OS 설정을 바꾼 뒤 새로 지도에 들어가 비교한다.

### P3 — 토큰·CSS 덮어쓰기 유지보수 부담

- 상태: **WARNING**, 현재 화면 깨짐을 단정하지 않는다.
- 정적 집계: `src/styles.css` 50,602 bytes, hex 표현 222종(알파 변형 포함), px 문자열 1,005회, 변수 정의 37회. `src/shell.css` 6,557 bytes, hex 표현 26종, px 144회. 이 집계는 시각 색상 수나 결함 수가 아니다.
- `styles.css`의 기본값·폭·높이·세로 규칙과 후순위 `shell.css`에서 `.home-copy`, `.facility-copy`, `.activity-card-symbol`, `.reward-art`, `.reward-badge`, `.certificate` 등 일부 책임이 나뉜다. `#app` 및 복합 선택자로 충돌을 막은 부분이 있다. 반복 선택자의 상당수는 정상적인 미디어쿼리이므로 전부 중복 결함으로 세지 않는다.
- 기본/의미/컴포넌트 3계층 토큰, spacing 6단계, 폰트 4단계까지는 통합되지 않았다. 현재 완성도를 과장해 “한 토큰으로 전체 디자인 변경 가능”이라고 보고하면 안 된다.
- 권장: 출시 전의 추가 대규모 CSS 재작성은 피하고, 화면 검증이 끝난 뒤 화면별 소유권·동일 breakpoint를 합치는 별도 정리를 수행한다. 특히 높이 650/690과 폭 680/699의 서로 다른 경계를 다시 확인한다.
