# 전체 스테이지 조작 개선 · 2026-10-28

## 목적과 범위

열 활동의 판단·예상·비교·설계는 유지하면서 중간 확인, 같은 조작의 반복, 완료 뒤 이동을 줄였다. 기존 정답 기준, 교육 자료, 안전하지 않은 선택 차단, 저장 키, 예시 활동의 완료 제외, 인증서 발급 자격을 유지한다. 새 에셋이나 외부 서비스는 추가하지 않았다.

## 플레이 변화

| 활동 | 바뀐 흐름 |
| --- | --- |
| 도시 이상 신호 스캔 | 두 시기를 비교하면 수첩에 자동 기록. 다음 미수집 지점으로 바로 이동하며 자유로운 지점 선택도 유지. |
| 증거 판독실 | 선택·끌기 즉시 판단 피드백. 근거를 읽고 다음으로 진행. |
| 도시 활동 스캐너 | 자원 연결 시 즉시 기록하고 다음 미조사 지점으로 이어지는 버튼 제공. |
| 관련성 추적망 | 이유를 놓는 순간 관계를 확인. 읽기용 다음 버튼만 유지. |
| 해수면 미래 실험 | 목표 수위 베끼기와 같은 확인 문항 6회 반복을 제거. 준비된 조건에서 예상→실험→결과 비교. 이전 실험과 수위 차이, 예상과 다른 구역 수를 표시. |
| 영향 연쇄 분석 | 세 장을 놓으면 즉시 순서 판정. 틀린 순서는 끌어서 수정하고, 마지막 기록은 바로 완료. |
| 오늘의 기후 선택 | 선택지 위치를 라운드마다 바꾸되 저장되는 선택의 의미는 유지. 선택 결과를 자유롭게 비교하고 마지막 기록으로 완료. |
| 선택 비교와 실천 | A/B 실제 지표를 항상 나란히 표시. B 지표가 A 값으로 바뀌던 슬라이더 제거. 카드 선택 즉시 판단. |
| 미래도시 설계 | 시설 연속 배치와 연속 지우개 제공. 같은 시설 재배치는 비용·설계 버전을 바꾸지 않음. 중복된 구역 비우기 버튼 제거. |
| 기후 스트레스 테스트 | 다음 날씨로 이동하면서 해당 시험도 실행. 재시험 버튼은 폭염 시험까지 실행. 두 날씨의 최초·재시험과 실패 시 재설계는 유지. |

홈 이어하기는 진행 중 활동으로, 챕터 완료는 다음 시설로, 최종 활동 완료는 엔딩으로 연결한다. 엔딩의 다섯 기록은 모인 상태로 표시하며 인증서 버튼을 한 번 누르면 된다. 개념 영상은 기존처럼 건너뛰거나 다시 볼 수 있다.

빠른 자동 넘김 타이머는 없다. 정답의 근거와 실험 결과는 학생이 다음 버튼을 누를 때까지 남는다. 포커스는 정답 선택·관측 완료 뒤 다음 행동으로 이어진다. 효과는 국소적인 선택·기록 반응을 사용하며 동작 감소 설정을 존중한다.

## 줄인 조작

정답으로 진행하는 기본 경로의 필수 버튼 클릭을 코드 흐름으로 비교했다. 재시도·자유 탐색·영상 제어·지도 이동은 계산에서 제외했다.

| 제거한 버튼 클릭 | 횟수 |
| --- | ---: |
| 관측 수첩에 별도 기록 | 8 |
| 판단·관계·순서·비교의 중간 확인 | 28 |
| 마지막 라운드 뒤 별도 제출 | 5 |
| 물 실험의 동일한 확인 답 선택 | 6 |
| 도시 시험의 이동 뒤 별도 시작 | 3 |
| 엔딩의 기록별 연결 | 5 |
| **합계** | **55** |

수위 슬라이더 맞추기 6회와 비교 슬라이더 조작도 제거했으며, 위 클릭 수에는 포함하지 않았다.

## 기존 저장 호환과 독립 검토

- 이미 비교했지만 수첩 버튼을 누르지 않은 관측은 자동 수집으로 복원한다.
- 올바른 세 장이 배치됐지만 확인 전인 순서 기록은 바로 다음으로 진행할 수 있다.
- 기존 많은 비 시험 대기 상태는 올바른 날씨 이름으로 이어진다.
- 재탐구 중에는 직전 완료 증거를 후속 활동에 제공하는 기존 구조를 유지한다.
- 별도 검토자가 저장·완료·포커스·재시험 경로를 검토했고, 발견한 호환 문제를 수정했다.

## 검증

- `npm test`: 학습 모형·안전·저장·해금·인증서·지도 단위 검사 15개 통과.
- `npm run check:interactions`: 열 활동, 터치 끌기/취소, 오답, 키보드, 새로고침, 예산 초과, 실패 도시 재설계, 영상 대체 경로, 동작 감소 등 24개 검사 통과. 페이지 오류 없음.
- `npm run check:flow`: 기존 저장 호환 3건과 관계 8라운드·영향 8라운드·생활 10장면·비교 4라운드 완주 등 7개 검사 통과. 페이지 오류 없음.
- 레이아웃: 906×755, 1024×768, 1280×720, 1366×768, 1920×1080, 873×580의 312개 화면 상태 점검. 발견한 720p·768p의 내부 스크롤을 수정하고 해당 두 크기의 104개 상태를 재검사했다. 최종 결과에서 화면 잘림·겹침·작은 터치 영역·20px 초과 작업영역 스크롤·페이지 오류 없음.
- `npm run build`: 최종 소스 구문 검사와 `dist/` 생성 통과.
- 브라우저 검사 산출물: `.tmp/experience-check/interactions.json`, `flow-resume.json`, `layout-final.json` 및 화면 캡처. 최종 레이아웃 결과에는 최초 전체 검사와 수정 영향 범위 재검사의 출처를 함께 기록했다.

검증은 로컬 Chrome 자동화이며 실제 태블릿·교실망이나 운영 배포 검수를 대신하지 않는다. 외부 배포는 수행하지 않았다.
