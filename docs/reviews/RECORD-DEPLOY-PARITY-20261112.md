## 추가 발견과 복구

개념영상의 장면 버튼 CSS가 대화상자를 연 뒤 동적으로 로드되어, 특정 타이밍에 높이가 약 27px인 기본 버튼으로 나타났다. 초기 HTML에 해당 스타일시트를 연결하고 최소 터치 높이를 48px로 맞췄다. 재발 방지 단위 검사를 추가했다.

873×580의 홈 음성 버튼은 스크롤 가능한 본문 아래에 있었다. 두 음성을 강제 클릭 없이 실제로 눌렀고, 화면 검사기도 스크롤 후 접근을 검증하도록 보완했다.

과거 기록의 “새 음성 생성 대기”, “844×390 그래프 넘침”, “14px 도움 표지”는 각각 후속 음성 커밋, 그래프 수정 커밋, 이번 도움 버튼 수정으로 해결된 역사적 상태다. 현재 미완료 항목으로 다시 남기지 않았다. 교사 검수·실기·사람 청취는 계속 미확인으로 남긴다.

## 공개 환경에서 발견한 오프라인 결함 복구

첫 공개 검사에서 `/index.html`이 `/`로 307 리다이렉트되는 것을 확인했다. 기존 빌드는 리다이렉트된 문서를 캐시해 온라인 화면이 정상이어도 오프라인 새로고침이 `ERR_FAILED`로 실패했다.

운영과 같은 리다이렉트를 재현하는 `dev.mjs --dist --redirect-index`에서 먼저 같은 실패를 확인한 뒤, 시작 문서를 `/`로 프리캐시하고 오프라인 문서 대체 경로도 `/`로 바꿨다. 캐시 버전 계산에 빌드 스크립트를 포함해 서비스워커 생성 로직 변경도 새 캐시로 전환되게 했다. 학습 기록은 독립된 localStorage에 유지된다.

수정 후 리다이렉트 재현 서버에서 오프라인 새로고침·WebM·MP4 부분 응답·H.264 탐색·도움말 5개 모두 통과했고 단위 테스트 54개도 통과했다. 증거는 `redirect-offline-red.log`, `redirect-offline-green.log`다. 후속 운영 버전이 앞의 첫 배포를 대체한다.

### 최종 재배포 확인

최종 운영 소스는 `4b2fd082fee46668dc71e206c27cb068fe8af343`이며 버전 `eafb94b4-cd0a-43a2-8401-942fa4039de7`에 트래픽 100%를 확인했다. 최종 `public-after.json`의 162개 파일에서 차이는 0개다.

공개 주소의 오프라인·미디어 6개 검사가 통과했다. 도시 운영 미션 3단계는 8개 화면 크기에서 완주했고, 40개 음성 연결 실제 클릭과 8개 음성 제어 검사가 통과했다. 원래 기록에 적힌 72단위 완주·인증서 다운로드·새로고침·상호작용도 공개 URL에서 다시 통과했다.

첫 접속 6,451ms와 모의 제한 네트워크 반복 2,439ms를 함께 기록했고, 최종 성적표에 첫 접속 경고를 반영했다. 이미 열어둔 탭은 자료 갱신 후 새로고침해 확인한다.
