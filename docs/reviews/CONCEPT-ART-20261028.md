# 주요 개념 이미지 고도화 · 2026-10-28

## 변경 범위

전체 화면을 검토해 이미 완성된 홈·지도·시설 배경은 유지하고, 핵심 개념을 단순 아이콘·도형·같은 장면으로 표현하던 부분을 새 생성 그림으로 교체했다. 이전 조작 개선의 자동 기록·즉시 판단·연속 시설 배치·직접 다음 이동은 유지한다.

| 대상 | 이전 표현 | 현재 표현 |
| --- | --- | --- |
| 도시 시설 5종 | 잎·물방울·방패 등의 공통 SVG 기호 | 도시숲·그늘 쉼터·빗물 저류지·안전 대피소·빗물 흡수 길의 구체적인 형태 |
| 해안 지형 6종 | 글자 카드와 일률적인 CSS 수면 | 해변·도로·습지·주택·공원·학교의 개별 일러스트와 실제 실험 판정 표시 |
| 생활 선택 10장면 | 모든 상황이 같은 침실 | 집·등굣길·교실·급식·더위·재사용·수선·냉방·물병·전원 관리 장면 |
| 자원 조사·관계·영향 연결 | 글자 중심 | 해당 활동과 장소를 보여 주는 문맥 그림, 벌채와 가뭄 구분 |
| 시설 입구·관측·실천 선택 | 공통 기호와 글자 | 각 장의 개념과 실천을 설명하는 그림 |
| 개념 영상 10종 | 단순 도형 중심 SVG 모션 | 생성 일러스트와 코드로 계산한 비교 막대·수면·시설 배치 움직임 |

그래프·숫자·땅 높이·정답·위험·자막은 코드와 DOM이 관리한다. 생성 그림에 계산 결과나 조작 UI를 넣지 않았다. 영상의 숲 보전 설명에는 보전된 숲을 사용하고, 벌채 그림은 숲 변화 조사에만 사용한다. 수선 장면은 그림과 설명이 맞도록 가방 수선으로 통일했다.

- 제작 스크립트: `scripts/prepare-concept-art.mjs`. 크기·용량·원본 SHA256은 `docs/concept-art-manifest.json`.
