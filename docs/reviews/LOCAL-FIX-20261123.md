## 구현한 4건

### 활동 4: 타당한 연결을 ID로 판정

`src/activity-data.js`에 이유 ID, 제시할 선택지, 인정할 이유를 명시하고 `src/activity-rules.js`에서 의미 ID로 채점한다. 표시 순서는 판정 기준이 아니다.

| 장면 | 인정하는 이유 ID 및 정확한 보기 |
|---|---|
| 물건 만드는 곳 | `production-inputs`: 새 물건 생산에 원료와 에너지가 필요해요. |
| 물건 만드는 곳 | `less-new-production`: 새로 만들 물건과 자원 사용을 줄여요. |
| 숲의 변화 | `forest-loss`: 이산화 탄소를 흡수하는 나무가 줄어요. |
| 숲의 변화 | `trees-absorb`: 나무가 이산화 탄소를 흡수해요. |

질문은 두 설명을 잇는 타당한 이유가 둘 이상일 수 있다고 안내한다. 물건을 오래 쓰면 생산 부담이 줄어드는 과정, 나무의 흡수 성질과 벌채의 관계를 각각 설명한다. 다른 장면에서 사실인 보기는 사실임을 인정하고 현재 연결과 다른 이유를 알려 준다. 명백한 오답인 ‘사진 속 모습만으로 모든 영향을 확정해요.’에는 사진 한 장의 한계를 설명하고 재시도를 허용한다.

오답별 설명은 가운데 카드에 표시한다. 기존 일반 재시도 음성은 하단의 동일한 원문과 함께 유지했다. 새 설명을 기존 음성이 읽는 것처럼 표시하지 않는다. 기존 v1의 숫자 선택은 종전 의미 순서로 해석하고 새 `selectedId`로 저장한다. 이미 완료된 링크와 완료 상태를 초기화하지 않으며, 저장된 링크의 `site/middle/end` 구조도 유지한다.

### 활동 3: 조사 주제의 기준을 명시

‘전기/연료/자원과 에너지/숲’ 대신 ‘조명·기기의 전기 / 이동에 쓰는 연료 / 물건·음식 만들고 쓰기 / 숲의 보전·변화’를 제시한다. 질문은 ‘장면에서 직접 조사할 주제는?’이다. 에너지의 종류나 자원의 출처를 배타적으로 나눈다는 인상을 피하고, 장면에 적힌 조사 활동으로 분류한다. 오답 안내에 ‘전기도 에너지예요’와 해당 조사 기준을 함께 설명한다. 물건 수선과 음식 낭비도 생산·사용·운반 과정으로 설명한다. 10개 조사 지점과 저장된 수집 기록은 유지한다.

시설을 선택·배치하는 동안 현재 더위, 빗물, 합계, 첫 시험 합계에 따른 기준, 더 줄일 값을 표시한다. 숫자는 ‘가상 모형값’이며 낮을수록 영향이 적다고 명시한다. 작은 가로 화면에서는 같은 시설·비용·효과를 담은 기본 선택 상자로 조작해 안내와 시설 조작을 함께 표시한다.
