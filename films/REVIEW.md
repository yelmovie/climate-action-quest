# 개념 영상 검토 · 2026-11-09

## 2026-11-13 · 잎새 앵무새 교체

잎새가 나오는 관측·자원·해수면·선택·설계 다섯 편에서 앵무새를 같은 위치에 넣었다. 질문, 그래프, 자막, 15초 타임라인과 무음 재생은 유지했다. 다섯 편의 HyperFrames 린트 오류는 0건이다. 1280×720 MP4/WebM과 마지막 장면의 WebP를 확인했다.

## 고른 것과 고르지 않은 것

- 6번 A안 "실험 노트"를 이 게임의 두 캐릭터로 옮겼다. 잎새(다람쥐)가 관측·자원·해수면·선택·설계 편, 물방울(수달)이 판독·연결·영향·비교·시험 편을 맡아 번갈아 나온다. 캐릭터는 자세 시트에서 잘라 쓰고 새 그림은 만들지 않았다.
- 고르지 않은 안: (B) 지도 위 시설을 카메라가 날아다니는 "기지 투어" — 활동 하나와 결론 하나가 흐려져 제외. (C) 캐릭터 대화극 — 내레이션·말풍선 글이 늘어 초4 읽기 부담이 커서 제외.
- 길이를 9초 → 15초로 늘렸다. 9초 안에서는 "질문 → 바뀜 → 결론"에 글을 읽을 시간이 모자랐다. 자막 세 칸을 0·5·10초로 옮겼고, 앱의 장면 버튼·자막 전환·재생 길이 표시가 같은 값(`CONCEPT_CUES`)을 쓴다.
- 영상 안 글자는 말풍선 질문, 이름표, 결론 한 줄뿐이다. 문장 설명은 앱 자막이 맡아 같은 문장을 두 번 쓰지 않는다.

## 잰 것과 본 것

- `hyperframes check --json`: 열 편 모두 오류 0. 남긴 경고: `nested_structure_needs_subcomposition`(무대·캐릭터를 한 파일에 둔 구조, 렌더와 무관), 결론 낱말이 회색→잉크로 바뀌는 0.2초 사이의 대비 경고(전환 중 표본), `duplicate_media_discovery_risk`(같은 시설 그림 두 번 사용), test 편 `text_below_floor`("남은 영향" 26px 보조 글자).
- `hyperframes snapshot`: 편마다 3.8·6.8·9.6·14.6초를 직접 보고 이름표 겹침(증거·영향·비교·시험 편), 확대 때 왼쪽 그림이 잘리는 문제(관측·해수면 편), `**` 표시가 그대로 보이던 결론(증거·해수면 편)을 고친 뒤 다시 봤다.
- 렌더: 1080p 원본 15.00초 확인 → 1280×720 mp4·webm, 편당 0.2–0.6MB(한도 2.5MB). 게시한 mp4에서 프레임을 다시 뽑아(0.2·5·8·12초) 확인했다.
- 소리: 없음(의도). 앱 플레이어가 muted로 재생한다.
- 아무도 확인하지 않은 것: 실제 태블릿·전자칠판에서의 글자 크기 체감, 사파리 재생.
