# 개념 영상 SPEC · 「잎새·물방울의 탐구 노트」 (2026-11-09)

6번이 정한 A안 "실험 노트" 방식을 이 게임의 캐릭터(잎새 다람쥐·물방울 수달)와 숲·크림·청록 색으로 옮겼다. 열 편이 한 부품(`kit/`)을 쓰고 무대만 편별 데이터(`films.data.mjs`)로 바꾼다.

```text
GOAL:    방금 끝낸 활동을 다시 보여 주면, 아이가 결론 한 줄을 자기 말로 말할 수 있다. 한 편에 한 생각.
OUTPUT:  HyperFrames 1920×1080 30fps → 앱용 1280×720 H.264(main, faststart)·VP9 WebM, 무음, 편당 ≤2.5MB + 마지막 장면 WebP(포스터·대체 그림)
TIME:    편당 15 s = 앱 자막 세 칸 0·5·10 s(src/concept-data.js CONCEPT_CUES). 장면 버튼도 같은 시각으로 이동.
         0–5 s  질문 말풍선 + 활동의 '전' 상태가 한 부분씩 생김
         5–10 s 바뀜(막대·수위·시설·줄긋기) → 바뀐 곳 0.9 s 확대(1.06–1.1배) → 이름표가 그 물체 위에, 그 물체가 바뀔 때
         10–15 s 결론 한 줄(흐린 글자 → 잉크, 열쇠 낱말 하나만 호박색) + 캐릭터 반응(찌그러짐 → 새 자세 → 복귀), 마지막 4 s 고정
LOOK:    종이 #FBF8F3(자세 시트 바탕과 같은 색) + 모눈 #D9E8DF 2px·60px·55%, 왼쪽 여백선 #E9C9B5
         잉크 #173F42, 초록 #1E665B, 민트 #BAD7B2, 물 #61ADCA, 녹 #C2703F, 강조 호박 #C9821C(테두리)·#9A5E0C(글자, 대비 3:1 이상)
         Jua 400(assets/fonts 복사본). 머리말 40px, 이름표 42px(+작은 줄 30px), 말풍선 56px, 결론 72px.
OBJECTS: 잎새(생각 → 놀람), 물방울(생각 → 환호): references/characters 자세 시트에서 잘라 바탕만 지움.
         그림: assets/concept-art(활동 화면과 같은 그림). 막대·수위·구역 위험은 activity-data.js와 evaluateCity 값 그대로(가상 교육 자료 표시).
MOTION:  도착 expo.out 0.5–0.8 s, 이동·확대 power2.inOut 0.7–0.9 s, 퇴장 power3.in 0.22 s. 이름표: 점 → 지시선 0.2 s → 카드 0.3 s back.out(1.6).
         말풍선 낱말 흐림 6px→0 0.13 s 간격 0.07 s, 결론 낱말 회색→잉크 간격 0.09 s. 착지한 글자는 움직이지 않는다.
SOUND:   없음. 플레이어가 영상을 muted로 틀고, 게임 효과음·배경음 설정과 내레이션은 영상 밖에서 관리한다.
BANNED:  어두운 바탕, 네온·빛번짐·떠다니는 입자, 보라/파랑 그라데이션, 유리 카드, 01/02 번호, 카드 세 장 나란히,
         모든 요소 동시 페이드업, 읽는 동안 움직이는 글자, 입자(분자) 모형, 근거 없는 수치·눈금 숫자, 공포 연출.
```

| 편 | 캐릭터 | 질문 | 무대(전 → 후) | 결론 |
|---|---|---|---|---|
| observe | 잎새 | 하루 기록만 보면 알 수 있을까? | 관측소 + '오늘 하루' 막대 → 더운 날 기록 예전 4·최근 4 막대(summer), 경향 점선 | 긴 기록에서 경향을 찾아요 |
| evidence | 물방울 | 눈이 온 날, 기후가 바뀐 걸까? | 오늘의 눈 카드 → 여러 해 평균 기온 막대(warm), '같은 장소·같은 기준' | 기후는 긴 기간의 기록으로 판단해요 |
| resources | 잎새 | 생활 속 어디에 자원이 쓰일까? | 빈 교실(전기) → 고쳐 쓰기(자원과 에너지) → 숲(숲), 사선으로 겹침 | 생활 곳곳에서 자원을 아껴요 |
| connections | 물방울 | 냉방과 기후는 어떻게 이어질까? | 창문 연 채 냉방 → 냉방 전기를 더 써요 → 창문 닫고 알맞게 냉방 | 활동 → 자원 → 대응으로 이어요 |
| water | 잎새 | 물이 높아지면 어디부터 닿을까? | 높이 1–5 여섯 장소(coastDistricts) → 수위 1·2·3, 낮은 주택가/언덕 공원 경계 | 낮은 곳부터 물이 닿아요 |
| effects | 물방울 | 물이 도로에 들어오면 어떻게 될까? | 해안 도로 → 물(변화) → 통행 금지(영향) → 다른 길·대피소(대응) | 변화 → 영향 → 대응을 이어요 |
| choices | 잎새 | 더운 날, 전기를 아끼려고 참을까? | 쉼터 장면 + 두 선택 → '참기' 줄긋기(몸이 위험해요), '물과 그늘' 확인 | 건강과 안전을 먼저 지켜요 |
| compare | 물방울 | 한 가지만 바꾸면 무엇이 달라질까? | 등교 두 선택의 게임 지표 [3,3,3] → [1,3,1] | 만족은 지키고 사용은 줄였어요 |
| design | 잎새 | 구역마다 어떤 시설이 맞을까? | 여섯 구역 더위·비 위험 → 시설 배치(18 중 16 사용) | 위험에 맞는 시설을 골라요 |
| test | 물방울 | 시설을 놓으면 정말 나아질까? | 같은 폭염: 시설 없음 남은 영향 16 → 시설 6 | 같은 조건으로 다시 시험해요 |

재현: `npm run concepts:render`(= `node films/build.mjs && node films/render.mjs`, `RENDER_DIR`에 외장 폴더 지정). `films/<id>/assets/`는 저장소 원본에서 매번 다시 만들므로 커밋하지 않는다.
