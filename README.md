# 기후 미래 작전실

숲속 연구기지를 탐험하며 관측 → 관련성 → 영향 → 생활 대응 → 도시 설계를 수행하는 교육용 웹게임 MVP. 스테이지 지도만 2.5D 픽셀 RPG이고, 시설 안은 2D다.

## 실행

Node.js 20 이상에서 설치 없이 실행한다.

```powershell
npm run dev
```

http://localhost:4173 에서 연다. `npm test`로 학습 모형·진행·지도 검증, `npm run build`로 배포할 `dist/` 생성, `npm run preview`로 배포본을 확인한다. 개발 서버가 켜져 있다면 preview는 다른 터미널에서 `$env:PORT='4174'`를 지정한다.

## 구현 범위

- 다섯 장·열 활동·72 탐구 단위. 기존 실행 코드가 없어 기획 기준 36→72로 확장했다. 72개의 객관식 문제가 아니라 관측·실험·선택·배치·검증을 합친 수다.
- 생성한 픽셀 지도와 학생·잎새 걷기 시트, 기존 일러스트 WebP, 로컬 Jua 글꼴.
- 길을 따라 자동 이동, 키보드/WASD·터치 방향판, 시설 순차 해금·복구 불빛.
- 관측 수첩·실험·생활 선택·도시 설계가 다음 활동으로 이어지고 매 행동을 자동 저장한다.
- 배지 다섯 종, 최종 연구 연결, 실제 완료 기록으로만 발급하는 인증서와 기록 다운로드.
- 공통 홈·이전·소리·설정. 설정에 학생/교사 가이드, 성취기준, 전체 해금, 소리 분리 제어, 초기화 확인을 제공한다.
- 배포본 서비스워커가 자료를 준비한 뒤 같은 브라우저에서 캐시된 활동을 제공한다. **자료 준비 전 또는 최초 미접속 기기의 오프라인 시작은 지원하지 않는다.**


## 개념 영상·조작 개선 · 2026-10-22

열 활동 완료 뒤 각각 15초 개념 영상을 보여 준다(2026-11-09 HyperFrames 재제작, `films/`). 완료한 시설에서 다시 볼 수 있으며, 영상 로딩 실패 시 마지막 그림과 세 문장의 개념 설명을 제공한다. 영상과 CC0 효과음은 로컬 자원이며 배포본의 오프라인 캐시에 포함한다.

카드 끌어 판단하기·자원 분류·이유 연결·순서 바꾸기·시설 배치를 지원한다. 끌기 대신 누르기·키보드로도 진행할 수 있다. 시간 비교 그래프·수면·생활 지표·도시의 남은 위험이 조작에 반응한다. 잎새와 물방울이 현재 행동과 추가 힌트를 안내한다.

[영상 설계](docs/CONCEPT-CLIPS.md) · [화면·조작 검증](docs/reviews/EXPERIENCE-20261022.md)

브라우저 검증 도구는 제작용이며 배포본에 포함하지 않는다. Playwright Core와 Chrome이 준비된 환경에서 개발 서버를 4175 포트로 실행한 뒤 `npm run check:layout`, `npm run check:interactions`를 사용한다. 배포본 서버(4275 포트)에서는 `npm run check:delivery`로 MP4 부분 요청·오프라인 영상·효과음 설정을 확인한다. 다른 포트는 `BASE_URL`, Chrome 경로는 `CHROME` 환경 변수로 지정한다.

## 스테이지 조작 개선 · 2026-10-28

관측은 두 시기를 비교하면 자동으로 수첩에 저장한다. 판단·이유 연결·순서 배치는 즉시 피드백을 보여 주고, 설명을 읽은 뒤 다음으로 진행한다. 물 실험은 준비된 수위에서 예상과 결과를 비교하며, 생활 선택은 화면 순서를 바꾸어 같은 위치만 누르는 반복을 줄였다. 비교 화면에는 두 선택의 실제 지표를 항상 표시한다.

도시는 시설과 지우개를 연속으로 사용할 수 있고, 다음 날씨 시험은 이동과 실행을 한 번에 한다. 마지막 라운드의 별도 제출과 엔딩의 기록별 연결 클릭을 없앴다. 이어하기는 진행 중 활동으로, 챕터 완료는 다음 시설로 바로 연결한다. 기존 저장·예시 활동·인증서 조건은 유지한다.

개발 서버를 4175 포트로 실행한 상태에서 `npm run check:flow`로 이전 저장 호환성과 여러 라운드 완주를 검사할 수 있다. [개선 내용과 검증 기록](docs/reviews/FLOW-POLISH-20261028.md)

## 주요 개념 그림 개선 · 2026-10-28

시설·해안 장소·생활 장면에 생성 일러스트 25장을 적용했다. 도시숲·저류지·대피소 등은 실제 시설의 형태를 보여 주고, 해안의 여섯 장소는 서로 다른 그림으로 구분한다. 생활 선택과 자원 조사에는 등굣길·급식·수선·냉방 등 상황에 맞는 그림을 연결했다. 기존 전체 배경은 유지하며 가뭄과 숲의 변화도 별도 장면으로 구분한다.

열 개념 영상은 같은 그림에 코드로 계산한 그래프·수면·시설 배치 움직임을 합성해 갱신했다. 설명·수치·정답 판단은 화면 텍스트와 활동 로직이 담당한다. 웹용 그림은 약 3.47MiB, 영상·포스터는 약 6.50MiB이며 원본 PNG와 제작 도구는 배포본에 포함하지 않는다.

그림 연결은 `src/concept-art.js`, 개별 크기·용량·원본 해시는 `docs/concept-art-manifest.json`에 있다. 원본은 `references/generated/concept-art/`, 프롬프트는 `docs/generated-prompts-*.json`에 보존한다. `node scripts/prepare-concept-art.mjs`로 웹용 그림을 만들고 `npm run concepts:render`(films/ HyperFrames, `RENDER_DIR` 지정)로 영상을 다시 만든다.

개발 서버를 4175 포트로 실행한 상태에서 `npm run check:art`로 이미지 파일·장면 연결·시설 교체와 삭제 시 그림 갱신을 확인한다. [그림 개선과 검증 기록](docs/reviews/CONCEPT-ART-20261028.md)

## 첫 화면·지도·교사 미리보기 개선 · 2026-10-30

첫 화면을 같은 시리즈 1~4번처럼 전면 일러스트·입체 로고·금색 시작 버튼·잎새와 물방울 캐릭터 구성으로 바꿨다. 지도는 화면을 꽉 채워 위아래 띠 없이 확대해 보여 주고, 카메라가 대원을 따라간다. 끌어서 둘러보기, 손으로 밀기, 지도 한눈에 보기를 지원한다.

교사용 전체 해금을 켜면 오른쪽 아래 "다음 단계 바로 가기"로 문제를 풀지 않고 다음 활동으로 넘어간다. 왼쪽 아래 이전/다음 화살표와 `Shift + ←/→`·`PageUp/PageDown`도 쓸 수 있다. 첫 화면 그림은 `node scripts/prepare-home-assets.mjs`로 다시 만든다. [개선 내용과 검증 기록](docs/reviews/FRONTDOOR-20261030.md)

## 저장과 운영

서버·회원가입·이름 입력·외부 분석 전송은 없다. `climate-future:v1`에 실제 활동 기록을, `climate-future:sound:v1`에 소리 설정을 저장한다. 관리자 전체 해금은 접근만 열며 수행 기록을 채우지 않는다. 예시 탐구는 인증서에서 제외한다. 초기화는 현재 게임 기록만 지우고 소리는 보존한다.

개발·미리보기·운영 도메인과 포트는 서로 다른 origin이므로 저장이 공유되지 않는다. 학교의 공용 기기에서는 사용 후 진행 초기화 여부를 교사가 결정한다. 저장 실패 시 안내하고 현재 세션 진행과 JSON 다운로드를 제공한다.

`dist/` 내용만 도메인 루트에 정적 배포한다. hash 라우팅이라 `/index.html#activity/4` 새로고침도 같은 파일을 연다. 하위 경로 배포는 절대 자원 경로 수정이 필요하다. 개발 서버는 로컬 검증용이며 운영용 서버가 아니다. 이번 작업에는 외부 배포를 포함하지 않는다.

## 유지보수

활동 자료는 `src/activity-data.js`, 활동 처리는 `src/activities.js`, 진행/저장은 `src/state.js`, 지도 좌표·경로는 `src/world.js`, 지도 렌더는 `src/map.js`, 설정 문구는 `src/settings-content.js`에 있다. 스타일은 공통 토큰 `src/styles.css`와 셸 전용 `src/shell.css`다. 활동을 늘리려면 데이터·렌더 함수·진행 범위·시설 연결을 함께 변경하고 `tests/`에서 선행 기록·예시·완료 조건을 확인한다.

가상 상대 자료는 실제 관측이나 예측이 아니다. 성취기준 전체 달성·실제 생활 실천·학생의 흥미를 이 앱만으로 입증할 수 없다. 원본 제공 이미지의 생성 계정과 상업 이용 권리, 실제 학교 기기·네트워크와 최종 운영 호스팅은 납품 전 확인해야 한다.
